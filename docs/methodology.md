# 방법론과 계산 정의

- 최종 선택값은 [사전 고정 기록](preregistration.md), 기계 판독 계약은 `configs/empirical.yaml`·`configs/extensions.yaml`에 있다.
- 설명·예측·운용은 타깃과 정보 집합이 다르다. 설명력이 높아도 다음 달 예측이나 거래비용 차감 성과를 보장하지 않는다.

## 설명과 시변성

\[
r_{i,t}=\alpha_i+\beta_{D,i}'X_{D,t}+\beta_{E,i}'X_{E,t}+\epsilon_{i,t}
\]

- 국내/전체 회귀는 자산별로 정확히 같은 관측월과 결측 마스크를 사용한다. 단일 회귀도 비교를 위한 공통 표본으로 계산한다.
- QR로 OLS를 풀고 SVD로 rank·condition number를 점검한다. rank 부족·과도한 공선성은 추정 실패로 표시하며 임의의 유사 역행렬 계수를 유의한 결과로 제시하지 않는다.
- Newey–West는 Bartlett 가중치 `1-lag/(L+1)`, 기본 `L=3`, 유한표본 보정 `n/(n-k)`를 사용한다. 개별 계수 구간은 잔차 자유도의 t 근사, 대외 계수군 Wald는 점근 χ² 근사다. 두 종류의 근사가 유한표본에서 정확하다는 보장은 없다. [Newey & West 원 논문](https://www.nber.org/papers/t0055).
- H1은 외부 계수군=0의 공동 검정 두 개에 Holm을 적용한다. 조정 R² 변화·계수의 크기/구간·기간/변수 제거 민감도를 함께 본다. raw R²의 기계적 증가로 지지 판정하지 않는다.
- rolling 창은 달력 60개월, 민감도 48/84개월이다. 원단위 계수와 창별 표준화 계수를 모두 저장한다. 표준화 척도 자체의 변화와 실제 계수 변화를 구분한다.
- 시변성 결과는 중첩 창의 기술 분석이다. 부호 변화나 점별 구간만으로 유의한 구조변화·레짐 전환·인과 충격을 선언하지 않는다.

## 예측

\[
y_{t+1}=r_{EQ,t+1}-r_{BOND,t+1},\qquad
R^2_{OOS}=1-\frac{\sum(y-\hat y_{model})^2}{\sum(y-\hat y_{historical\ mean})^2}
\]

- 기준 평균은 매 cutoff까지 관측된 타깃으로 매월 다시 추정한다. AR(1)의 lag도 당시 가용 버전을 사용한다.
- OLS/Ridge의 스케일러·모수·Ridge alpha 선택은 학습 창 내부에서만 적합한다. 전체 표본에서 피처를 골라 같은 기간 OOS를 보고하지 않는다.
- 모든 모형은 같은 판단월·다음 달 타깃·109개 평가월을 사용한다. 평균 오차제곱합이 0이면 OOS R²는 결측으로 표시한다. RMSE·MAE·방향성 적중률은 보조 지표다.
- 역사적 평균 대비 비교와 OOS R²의 동기는 [Campbell & Thompson (2008)](https://dash.harvard.edu/entities/publication/73120378-7dd1-6bd4-e053-0100007fdf3b)을 참고하되, 해당 논문의 미국 주식 결과를 한국 ETF에 적용된 결과처럼 주장하지 않는다.
- 원형 블록 재표집은 같은 실제/모형/기준 예측 오차 인덱스를 함께 뽑는다. 5,000회·6개월 블록, 3/12개월 민감도. 95% 점별 구간과 평균 대비 4개 모형의 Bonferroni 동시 구간을 함께 저장한다.
- 이 구간은 실현된 예측 손실 경로를 요약한다. 학습 과정 전체를 다시 생성한 무조건적 신뢰구간이 아니며, 중첩·규제·튜닝에 공통인 엄밀한 우월성 p-value가 아니다.

## LightGBM과 SHAP

- 공식 [LightGBM 4.6.0](https://lightgbm.readthedocs.io/en/stable/Installation-Guide.html)의 native CLI를 사용한다. 연구 코드는 TypeScript이며 Python 실행 wrapper를 쓰지 않는다.
- 얕은 트리 4후보, leaf 최소 20개, L2=5, 학습률 0.03, 1 thread·고정 seed. 각 OOS cutoff에서 마지막 18개월의 3개 origin·6개월 블록으로 내부 검증한다. 각 origin 이후의 타깃을 학습에 넣지 않는다.
- `predict_contrib=true`는 feature 수+1 열을 출력하며 마지막은 expected value다. 매 OOS 행에서 feature 기여+expected value가 예측과 1e-8 이내로 일치하는지 검사한다. [공식 예측 파라미터](https://github.com/lightgbm-org/LightGBM/blob/v4.6.0/docs/Parameters.rst).
- 평균 절대 SHAP, 시점별 SHAP, 연도/기간별 안정성, 국내/대외 그룹 기여와 통화 피처 제거 실험을 보고한다. 그룹 기여는 부호 있는 기여를 합친 뒤 절댓값을 취한다.
- SHAP은 모델의 예측 기여다. 인과효과가 아니며 상관된 변수 간 중요도 배분은 불안정할 수 있다. [LightGBM 논문](https://papers.nips.cc/paper/2017/hash/6449f44a102fde848669bdd9eb6b76fa-Abstract.html), [SHAP 논문](https://papers.nips.cc/paper/2017/hash/8a20a8621978632d76c43dfd28b67767-Abstract.html).

## 체결·비용·NAV

- P4 월말~월말과 P5 다음 공동 거래일 종가~다음 체결일 종가를 분리한다. 예측월 전체 수익에 신규 비중을 소급 적용하지 않는다.
- NON_MACRO의 3개 피처는 과거 상대수익 1개월·3개월 평균·12개월 변동성이다. MACRO_TAA에는 거시 6개만 더한다. 둘의 common mask·Ridge 후보·내부 검증·비중 정책·비용·OOS를 동일하게 유지한다.
- 목표 주식 비중은 `0.5 + 0.2*tanh(예측/학습 타깃 표준편차)`, 나머지는 국채다. 공매도·레버리지 없이 합계 1이다. 거시 피처를 제거하면 비거시와 같은 절차로 환원되는지 테스트한다.
- 직전 가격 변동을 반영한 체결 직전 자산금액을 `V_i`, 목표 비중을 `w_i`, 편도 비용률을 `c`라 하면, `NAV_after + c*Σ|w_i*NAV_after−V_i| = NAV_before`를 이분법으로 푼다. 비용을 뺀 뒤에도 목표 비중 합계와 자기금융 조건을 충족한다.
- 보고 회전율은 `0.5*총거래금액/NAV_before`, 비용은 매수+매도 총거래금액에 적용한다. 기본 10bp, 민감도 0/5/25bp. 배당락일 재투자 거래비용도 차감한다.
- CAGR은 체결 간 월별 수익의 기하 누적을 사용한다. 변동성은 월간 표준편차×√12, Sharpe는 ACT365 현금 프록시 차감, MDD는 실제 일별 계정 경로에서 계산한다. 평균 목표 주식 비중뿐 아니라 일별 드리프트 노출도 보존한다.
- 실제 ETF 가격과 분배금을 사용하지만 지급일까지의 미수금·결제 지연·시장 충격·정수주/유동성 제약을 전부 복원한 것은 아니다. **분배금 배당락일 재투자와 종가 체결을 가정한 이론적 백테스트**다.

## 검정력·결론의 범위

- 자산 월간 206개월·회귀 공통 205개월·109개 OOS라는 개수만으로 충분한 검정력을 선언하지 않는다. H1은 두 가설의 보수적인 alpha=0.025, 외부 변수 3개의 비중심 χ² 근사로 partial R² 2/5/10%의 탐지 민감도를 계산한다.
- 잔차 AR(1)에 따른 유효표본 축소는 보수적인 민감도 휴리스틱이다. HAC·설명변수 상관·구조 변화까지 반영한 정확한 검정력을 보장하지 않는다.
- OOS 최소 탐지 효과는 block-bootstrap 손실 평균 표준오차와 다중비교 기준에서 normal 근사로 환산한다. 실제 손실 변동성에 조건부인 사후 **설계 민감도**이며, 실현 효과를 대입한 ‘관측 검정력’이나 검증력 보장의 대체물이 아니다.
- 신뢰구간이 넓거나 작은 개선을 탐지하기 어려우면 결론을 ‘증분 가치를 확인하지 못함’으로 제한한다. ‘효과가 없음이 증명됨’이라고 쓰지 않는다.
