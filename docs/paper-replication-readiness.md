# 원문 동일자료 재현 · 선행 감사

상태: **미완료 — 동일자료 재현을 시작할 전제 미충족**. 이 문서는 기존 ETF 실험을 원문 재현으로 바꾸지 않는다. 기존 성과를 본 뒤 수행한 자료·소스 감사이며 새 성과는 계산하지 않았다.

## 사용자 조건 확정 이후의 진행

사용자는 원문 자료·패키지에 접근할 수 없고 공개 자료만 사용한다고 확인했다. 동일자료 재현의 미완료 상태와 별개로, 고정한 8개 ETF에서 원문 명시 방법을 검수하는 [공개 자료 방법 검증](public-method-reconstruction.md)을 진행했다. 저자 공개 CSV의 계산 대조와 ETF 원자료의 독립 특징·라벨·평균·공분산 검사가 통과했다. 새로운 투자 성과 실험은 하지 않았으며, 이것을 원문과 동일한 실증의 재현으로 바꾸어 부르지 않는다.

[공개 자료 범위](../configs/public_reconstruction_scope.json) · [실제 계산 검증 기록](../results/public_method_checks/verification.json)

## 순서에서 잘못된 점

원문의 자료·계산 절차를 재현해 기준선을 확인하기 전에 ETF 대체와 국면·ML 비교를 진행했다. 이후 ETF 진단을 늘렸지만, 그것으로 원문 대비 차이가 자료 때문인지 구현 때문인지 확정할 수는 없다. 기존 검증은 ETF 실험의 정보시점·회계·독립 재적합·재생에 대한 검증이며 저자 전체 실험과의 동등성 검증이 아니다.

## 확인한 일차 출처

- [arXiv v2 §2·§3·§4·부록 A](https://arxiv.org/html/2406.09578v2): Bloomberg를 통해 확보한 1991–2023년 12개 지수와 DGS3MO를 사용하고, 2007–2023년을 평가한다. 초기 학습은 1991–2001년, 초기 순차 검증은 2002–2006년이다.
- [저자 홈페이지](https://sites.google.com/view/yizhan-shu/home): 연결된 코드는 Jump Model 라이브러리다. 확인한 페이지에서 논문 전체 재현 패키지를 찾지 못했다.
- [저자 저장소](https://github.com/Yizhan-Oliver-Shu/jump-models/tree/d0fa00ce10126791695a259a45c5ddd41fbced80): 현재 master와 기존에 잠근 커밋이 같다. 전체 트리를 조사했다. Jump Model 구현·Nasdaq 예제·Nasdaq 자료는 있으나, 그 트리에는 논문의 12자산 패널, XGBoost 순차 실험, 배분 실험 스크립트가 없다.
- [출판사 공개 페이지](https://link.springer.com/article/10.1007/s10479-024-06266-0): 초록·주석·서지를 확인했다. 본문은 구독 안내가 표시되며, 확인한 공개 페이지에서 전체 자료/코드 다운로드를 찾지 못했다. 저자 SharedIt 링크는 로봇 확인으로 내용을 확인하지 못했다. 다른 경로에도 자료가 없다고 단정하지 않는다.

자료 접근 제한을 우회하거나 자료 구매·저자 연락을 수행하지 않았다. 저자에게 문의가 필요하더라도 별도 사용자 지시 없이 메시지를 보내지 않는다.

## 확보 상태

| 대상 | 현재 상태 | 원문 재현에 필요한 확인 |
|---|---|---|
| 논문·목적함수·표4/6/7 | 확인 | 표의 반올림 수치와 원시 기준 산출물을 구분 |
| Jump Model 라이브러리 | 확보·커밋 고정 | 논문 실행 당시 버전·초기화 확인 |
| 12개 지수 원자료 | 미확보 | Bloomberg 식별자, 1991–2023년 일별 USD 자료, 원본 해시 |
| 지수 연결 구간 | 원문 서술만 확인 | 장기국채의 1994년 이전 대체, 하이일드의 1999년 이전 펀드, REIT의 1992년 이전 대체 자료 |
| 전체 JM–XGB·배분 실행 코드 | 확인한 공개 트리에서 미발견 | 저자 실행 패키지 또는 항목별 구현 검수 |
| 잠긴 전체 실행 환경 | 미확보 | 예제 environment.yaml에는 XGBoost·Gurobi가 없어 논문 환경으로 간주 불가 |
| 중간 기준 산출물 | 미확보 | 선택 벌점·평활, 예측·조건부 평균·공분산·비중·거래·NAV |

원문 부록 A의 Commodity는 명칭이 Excess Return Index다. 이를 전 자산 공통의 총수익률 처리나 현금 이자 처리로 임의 해석하지 않고 저자 입력 정의를 확인해야 한다. 이번 ETF 실험의 상장 전 합성 이력 금지 원칙도 유지한다.

## 현재 구분해야 할 구현 차이

| 항목 | 확인된 사실 | 처리 |
|---|---|---|
| 예제의 특징 | 5·20·60일, 9개 특징 | 논문 표2의 5·10·21일·8개 특징을 대체하지 않음 |
| 예제의 EWM | pandas 기본 adjust=True | 현재 ETF adjust=False와 다름. 논문 실행 규약은 미확정 |
| 예제의 전처리 | 학습 자료로 3표준편차 clipping 후 표준화 | 현재 ETF는 표준화만. 논문에서도 clipping했는지는 미확정 |
| 자료·시장 입력 | 원문 12개 지수·S&P500–AggBond 상관 | 이번 8개 ETF·SPY–IEF 상관은 적용상 대체 |
| 현금·체결 | 원문 DGS3MO 대용 현금, 정확한 거래 수익 구간 확인 필요 | BIL 매매·다음 시가 체결과 별도 조건 |
| 벌점·모형 | 원문 기본 XGB, 로그 간격 후보 | 정확한 버전·격자·동률·평활 초기화 규약 확인 필요 |

예제와의 차이는 논문 구현 오류가 발견됐다는 뜻이 아니다. 반대로 저자 라이브러리를 사용했다는 사실도 이 차이들을 해소하지 않는다.

## 이후의 통과 순서

1. **자료·설정 확보:** 위 누락 자료와 미확정 규약을 확인하고 해시·출처·단위를 고정한다. 자료가 없으면 동일자료 재현은 미완료로 유지한다.
2. **기준 구현 검수:** 원문 자료로 계산할 수 있는 단순 수익·현금·기본 MV/MinVar/EW부터 맞춘다. 저자의 중간 산출물이 있다면 특징→JM→XGB→비중→NAV 순서로 비교한다.
3. **원문 실증 재현:** 2007–2023년 표4/6/7을 같은 정의로 산출한다. 원시 기준이 없을 때에는 발표 표의 반올림 구간과 비교하되, 이것만으로 경로가 동일하다고 판정하지 않는다. 재현 허용오차와 판정은 실행 전에 고정한다.
4. **ETF 대조:** 기준이 확인된 뒤 같은 평가기간·정보·배분을 유지하며 ETF·현금·체결 조건을 나눠 비교한다. ETF 실제 이력이 부족한 기간은 부족하다고 기록한다.
5. **연구 확장:** 국면 2/4와 XGB/LR의 추가 가치는 그 다음에 해석한다. 기존 A51/B51/F141/D51은 과거 ETF 응용 결과로 보존하며 새 원문 재현으로 소급 분류하지 않는다.

샤프가 양수이거나 원문보다 좋아졌다는 이유로 통과시키지 않는다. 임의로 고른 구현이 발표 수치에 가까워지도록 조정하지 않는다. 원문 재현이 불가능하면 공개 ETF 응용 연구라는 범위와 미확정 원인을 명시한다.
