# v2 실행 기록

2026-10-19 (Asia/Seoul). v1 성과를 본 뒤 원문과 대조하여 배분 수식 오류를 수정한 역사적 재분석이다. 독립 사전등록·미열람 전향 검증을 주장하지 않는다.

- v1 공개 커밋 `babba10b277496387acd600cf417262a69154cb1`, 실제 예측 실행 소스 `3bd48f7a58cc5d9f9253e9dd3a9b03479d3f7f33`과 원자료·예측·튜닝·거래·검정 파일을 보존했다.
- 수정 계약은 로컬 `75182bb`에서 수정판 성과 계산 전에 고정했다. 공개 설명·계약은 `734c733fd023349c5f87b58c9ea2da308a544053`으로 먼저 게시했다. 기존 조건을 성과에 맞춰 바꾸지 않았다.
- 최초 수정 배분 실행 소스는 `ddc1c3128a11154ba3e000186d7dfe4bd9b2a566`이다. 정확한 커밋 객체를 [32KB Git bundle](../archive/v2_execution_source.bundle)에 담고 [해시·선행 커밋](../configs/v2_execution_source.json)을 기록했다.
- R00을 먼저 실행했다. 네 예측 조합+국면 없는 MVO의 목표 비중 오차는 최대 약 `2.0e-13`, NAV 오차도 약 `2.0e-13`으로 [고정 허용치](../results/v2/r00_gate.json)를 통과한 뒤 R10·R01·R11을 계산했다.
- 주 분석은 72개 계정이고 입력 제거3개·경제6개월은 각각9개 계정, 합계108개다. 비용 운영 계정은 각자 종가 드리프트를 이어받아 전체 경로를 계산했다. 별도 fee_only 진단만 목표 경로를 고정했다.
- 최초 파일을 로컬 비공개 보관한 뒤 거래 파일을 작은 Parquet 묶음으로 압축·분할하고 ET 시각 열을 추가했다. 15개 표의 기존 모든 열을 변환 전후 직접 대조했고 [내용 해시](../results/v2/packaging.json)가 일치했다. 이후 소스 `8d93fed`는 이 포장과 독립 검산을 추가한 것이며 배분 수식·예측 설정을 변경하지 않았다.
- 대표 세 학습 경계 2013-12-31·2020-06-30·2025-06-30에서 48개 자산/정의, 96개 분류기를 독립 재적합했다. 미래 ETF 가격·FRED·ALFRED 빈티지·미발표 라벨 교란도 통과했다. 동일 실행 중 별도 프로세스로 완료한 [재학습 증거](../results/v2/forecast_reverification.json)의 원자료/예측/소스 해시를 검증 단계에서 다시 대조했다.
- 수정판의 실제 보유 비중·다음 시가 교란 검사를 추가했다. 대표 60개 실제 배분의 목적함수 최적성은 CVXPY를 쓰지 않는 독립 선형계획 상계로 검산했고, 개선 가능성 상계 최대는 `5.73e-11` 일별 단위였다(허용치 `2e-7`).
- 108개 계정의 전체 경로를 독립 shares+Brent 근 찾기로 재생했다. 판단·체결 시점, 비용 1회 차감, NAV 항등식, 종가 드리프트, 확률·제약·자료 해시 검사가 [실제 원자료 검증](../results/v2/verification.json)에서 통과했다.
- 주 비교·입력 제거·경제6개월의 월별 검정과 블록3/6/12 결과를 생성했다. 15개 단위검사, ruff, 원자료 없는 [산출물 검증](../results/v2/verification_artifacts.json)을 수행했다. 공개 CI는 저장소 [Actions](https://github.com/bucheoncityboy/korean-macro-factor-allocation/actions)에서 별도로 확인할 수 있다.
- v1의 경제4 우위 판정을 수정했다. 수정판 세 주요 비교는 기본 블록6의 동시 구간에서 모두 우위 미확인이다. 경제6개월 부록에서 나타난 XGB2−로지스틱2의 양의 구간을 새 주 결과로 선택하지 않았다.
- 원문의 약세 예상수익 −10bp 경계 방향은 미확정이다. 무경계·하한·상한 세 대조를 모두 고정·공개했고 원문 전체 재현이라고 부르지 않았다.
