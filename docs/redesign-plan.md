# 원문 준거 중심 재구성안

상태: 원문 실증 구성 및 재검수 반영판 v4. 새 실험의 실행 계약·구현·실행 결과가 아니다. 이전 결과를 열람한 뒤 작성한 역사적 진단 계획이며 전향 검증이나 최초 사전등록으로 부르지 않는다. [검토 기록](redesign-review.md)

현재 요청의 중심은 원문 실증처럼 ‘국면 예측을 넣은 뒤 기본 배분의 투자성과가 개선되는가’를 보여주는 것이다. 첫 제출 묶음은 아래5절의 자산별 성과표·배분 전후 표·NAV/낙폭 그래프·노출/비용 해석이다. CER0.50%p 검출이나 새 진단30개 완료가 이 성과 비교의 의미를 대신하지 않는다. 전체 재구성의30개 진단은 기존 범위로 유지하되 원문형 실증을 제시한 다음 원인을 설명하는 단계로 실행한다.

## 1. 목적과 기존 결과의 지위

| 구분 | 답할 질문 | 평가기간·처리 |
|---|---|---|
| A51 원문 준거 | 원문의 배분 개선 방향이 실제 ETF에서도 유지되는가? | 2021-07-01–2025-09-30, 51개월. 기존 A 및 기본 MV·MinVar·EW 재사용 |
| B51 통제 비교 | 국면 정의와 분류기의 추가 가치가 있는가? | 같은 51개월. 기존 B의 네 조합과 세 주요 CER 대비 유지 |
| F141 장기 후속 | 변경된 설계에서 장기 결과와 정책 민감도는 어떠한가? | 2014-01-02–2025-09-30, 141개월. 기존 결과·모든 변형 보존 |
| D51 새 진단 | 설정 변경이 같은 표본의 예측·비중·비용·성과에 어떻게 작용하는가? | 같은 51개월. 아래 닫힌 실험 목록만 새 계약의 대상으로 사용 |

원문 준거를 먼저 설명하는 것은 보고 순서 변경이다. A51·B51·F141의 기존 계약, 주 설정, 주 비교, 결과를 소급 변경하지 않는다. 원래 세 주요 비교를 새로운 원문 재현 질문으로 대체하지 않는다. 새 진단 결과가 좋더라도 주 전략으로 승격하지 않는다.

A51은 예측·평균 추정·위험회피·거래벌점·현금 규칙을 포함한 배분 묶음의 비교다. 원문과 기존 A의 기본 MV는 위험회피 5·거래벌점 0이고, 국면형 MV는 10·1이다. 따라서 A의 샤프 차이를 XGBoost 단독 효과라고 부르지 않는다. ML 분류기의 추가 가치는 B51의 동일 배분 내 XGB 대 로지스틱으로 판단한다.

## 3. 원문 준수 감사를 먼저 통과한다

각 항목에 원문 절·표·수식, 실제 코드 위치, 판정 근거를 남긴다. 상태는 `일치`·`적용상 대체`·`명시적 변경`·`원문 미확정` 네 가지다. ‘구조가 같다’와 숫자·추정 대상까지 같다는 판정을 구분한다.

- [원문3절](https://arxiv.org/html/2406.09578v2#S3): JM·표적 정렬·수익/시장 특징·11년/5년 창·갱신·선택·평활을 대조한다.
- [원문4절](https://arxiv.org/html/2406.09578v2#S4): 평균·공분산·위험회피·거래벌점·제약·현금 규칙·기본 배분을 대조한다.
- 실제8개 ETF·BIL·다음 시가 체결·FRED 지연, SPY–IEF 상관은 적용상의 차이다. 지수 소급·합성 이력·최신 빈티지 덮어쓰기로 차이를 없애지 않는다.
- 원문 XGB 버전, 벌점 격자의 정확한 개수, 평활 선택의 세부 순서, JM 단독 기준모형의 벌점, MinVar 기본 상수 평균 크기, 약세 평균의 −10bp 제한 해석은 확정되지 않은 부분을 그대로 표시한다.
- XGB 2.1.4의 기본 깊이6·100회·학습률0.3·L2=1과 실제 resolved configuration은 ‘우리의 고정된 구현’이다. 원문 버전과 완전히 같다고 주장하지 않는다.
- A의 약세 평균 하한/상한 두 결과와 발표된 평활·IEF DD 민감도를 유지한다. 아래 A0는 이미 공개한 `mv_jmxgb_floor` 호환 기준일 뿐 올바른 해석이나 우승 설정으로 재선정한 것이 아니다.
- 12개 중 강세3개 이하인 조건을 8개에 적용한 상대적 차이도 표시한다. 기존 결과가 낮다는 이유만으로 문턱을 재조정하지 않는다.

일치 판정과 재사용 근거가 없거나 새로운 구현 오류가 발견되면 해당 결과의 재사용을 중단한다. 오류 증거·영향 범위·별도 수정 계약을 기록하고 필요한 범위를 재실행한다. 기존 결과 재사용을 이유로 오류 수정을 막지 않는다.

## 4. D51의 비교 대상과 고정 범위

기준 A0는 A51의 `mv_jmxgb_floor`·5bp 계정이다. D51은 MV 계정 진단이며 새 MinVar/EW 실험을 암묵적으로 추가하지 않는다. 모든 신규 계정은 동일한51개월·초기 NAV1·초기 BIL100%에서 시작한다.

세 종류의 효과를 분리한다.

1. `fixed_path`: 해당 시점 A의 선택 벌점·JM 라벨·라벨 모델 ID·평활 선택을 고정하고 선언한 요소만 바꾼다. ‘당시의 선택 경로에 조건부인 진단’이며 변경된 모형의 최적 튜닝 성과가 아니다.
2. `selection_policy`: 후보별 과거 순차 예측은 유지하되 선택창을 바꾼다. 선택된 벌점·그에 따른 라벨/평균/주문 변경은 선언한 파생 효과다. 고정 라벨 진단과 섞지 않는다.
3. `pipeline_bundle`: JM·분류기·평균 추정 이력 등을 함께 바꾼 시스템 비교다. 한 요소의 순수 효과라고 부르지 않는다.

공통51개월은 평가 표본 차이를 통제한다. 한 표본의 성과 차이를 일반적인 인과효과나 원문과의 전체 성과 차이 중 몇 %를 설명하는 값으로 해석하지 않는다.

### 4.1 분류·선택 진단: 11개 계정

특별히 적지 않은 분류기·JM·평균·공분산 이력은 A0의11년, 검증은5년이다. F01–F09와 S01·P01은 각각 하나의 MV 계정을 만든다.

| ID | 기준 | 선언한 변경 | 효과 종류 |
|---|---|---|---|
| F01 | A0 | 분류기 학습만11년→5년. JM과 평균·공분산은11년, 분류 표준화는5년 표본에서 다시 적합 | fixed_path |
| F02 | A0 | 분류 입력13→17. JM 입력은 유지 | fixed_path |
| F03 | A0 | 학습손실에 월별 동일 기여 가중치, 총합은 표본수N | fixed_path |
| F04 | F03 | 같은 상대 가중치를 월별 합1로 축소, 총합M | fixed_path |
| F05 | A0 | XGB 깊이6→2만 변경 | fixed_path |
| F06 | A0 | XGB 학습률0.3→0.03만 변경 | fixed_path |
| F07 | A0 | XGB L2 1→5만 변경 | fixed_path |
| F08 | A0 | 깊이2·학습률0.03·L2=5를 함께 적용. 100회 유지 | fixed_path 안의 모형 설정 묶음 |
| F09 | A0 | 선택된 자산별 평활을4일로 변경, 원래 선택 벌점 경로 유지 | fixed_path |
| S01 | A0 | 벌점 선택 검증창만5년→3년, A의 초기 선택 평활과 XGB 단독 점수 기준 유지 | selection_policy |

F03/F04에서 N은 가용한 학습 표적 수, M은 그 표적의 관측월 수, n_m은 월m의 표적 수다. F03은 `w_i=N/(M*n_m)`, F04는 `w_i=1/n_m`이다. 상대적인 월 비중과 손실의 절대 크기를 따로 비교한다. 두 진단과 아래 I01에서는 사전확률·미관측 클래스 질량은 같은 A 학습 표적에서 계산한 기준 벡터로 고정해 학습손실 가중치와 구분한다. B의 월 가중 정책 전체를 재현한 진단이라고 부르지 않는다.

가중치 크기는 L2 외에 `min_child_weight` 같은 절대 문턱과도 상호작용한다. I01은 L2와의2×2 진단에 한정하며 모든 학습 스케일 효과를 L2로 설명하지 않는다. 새 분류기 적합에는 실제 가중치 합·사전확률·resolved config·학습/평가 손실과 트리 깊이·분할 없는 트리 수를 기록한다. 이 기록을 이유로 선언하지 않은 하이퍼파라미터 탐색을 추가하지 않는다.

P01에서 바뀌는 JM 라벨·상태 평균·선택 경로는 묶음 변경 목록에 포함한다. F01과 P01의 차이를 숨기지 않는다. S01의 새로운 벌점에 연결된 평균도 그 후보 JM에서 추정된 값을 쓰고, 원래 선택 라벨을 억지로 유지하지 않는다.

### 4.2 평균·노출·공분산 진단: 7개 계정

모든 행에서 예측은 A의 같은 시점 확률을 재사용한다. 각 행은 하나의 MV 계정이다.

| ID | 기준 | 선언한 변경 |
|---|---|---|
| M01 | A0 | 경성 국면→확률 혼합. 같은 상태별 평균에 같은 약세 제한을 먼저 적용한 후 혼합 |
| M02 | A0 | 일별 단순 상태 평균에252개 거래일 상당 축소만 추가 |
| M03 | A0 | 상태 평균 추정에만 월별 합1 가중치 적용. 축소0 유지 |
| M04 | A0 | 상태 평균의 수익 기준만 DGS3MO→실제 BIL 초과수익으로 변경. JM 특징·라벨과 공분산 수익 기준 유지 |
| M05 | A0 | 강제 현금 대피만 제거 |
| M06 | M05 | 예상수익 생성방식만 기존 기본 MV의 과거 EWMA1260으로 교체. 위험회피10·거래벌점1·현금 대피 없음은 양쪽 동일 |
| M07 | A0 | 공분산 추정 이력만11년→5년. EWM252·수익 기준 유지 |

M02는 일별 동일 가중 단위에서 `mu_k=(sum(r_k)+252*mu_all)/(n_k+252)`로 정의한다. 월 가중과 BIL 기준을 함께 바꾸지 않는다. F141의 월 가중·12개월 축소·BIL 평균 전체를 동일하게 재현한다는 뜻이 아니다.

M03의 가중치는 수익과 라벨이 모두 알려진 공통11년 이력 전체에서 월별 합1로 한 번 계산한다. 상태별로 월 가중치를 다시 정규화하지 않고 `mu_k=sum(w_i*r_i*1[label_i=k])/sum(w_i*1[label_i=k])`로 추정한다. 빈 상태는 같은 알려진 이력의 전체 평균을 사용하고 기록한다. M01–M04의 평균 추정 후 약세 하한 적용 순서는 A0와 일치시키고, M01은 상태별 제한 후 확률을 혼합한다.

M05 대 M06은 같은 최적화 조건의 국면형 예상수익 생성방식 대 무국면 예상수익 생성방식 진단이다. M06은 현금 대피뿐 아니라 강약세 마스크와 약세 평균 제한도 사용하지 않는다. 제한 제거는 예상수익 생성방식 변경에 포함되는 선언된 파생 항목이다. JM 확률·라벨만 교란해도 M06의 평균·주문·NAV는 유지되어야 한다. JM·조건부 평균 추정까지 포함한 두 방식의 비교이므로 XGBoost 단독 효과라고 부르지 않는다.

### 5.1 원문형 실증의 핵심 산출물

표4·표6 형태의 비교는 A51의 검증된 저장 계정에서 먼저 생성할 수 있다. 표7 형태의 상관 진단은 원문 준수 감사 후 고정한 계산 정의로 생성·검증해야 하며 기존에 완료된 것으로 표시하지 않는다. 새로운 투자 계정이나 모형 튜닝을 추가하지 않는다. 기존 JM 단독 기준은 XGB와 벌점을 공유하므로 ‘같은 라벨/선택 경로에 조건부인 유지 기준’임을 표시한다. 원문도 JM와 JM–XGB 비교의 튜닝·입력 차이를 논의하므로 이 표만으로 XGB 단독 효과를 확정하지 않는다.

표6의 일별 계정 순수익을 `r_p`, 같은 날짜의 BIL 보유 순수익을 `r_b`라 하면 주 지표는 `e=r_p-r_b`, `R=252*mean(e)`, `V=sqrt(252)*std(e, ddof=1)`, `S=R/V`다. MDD는 비용 차감 계정 NAV의 초기값1을 포함한 고점 대비 낙폭이다. CAGR은 `prod(1+r_p)^(12/관측월수)-1`이며 R 대신 같은 이름으로 표시하지 않는다. `V=0`인 새 계산은 `undefined_zero_volatility`로 기록한다. 기존 BIL 샤프0 관례를 재사용할 때는 그 관례를 표시한다.

Calmar는 원문 표6 수치와 일관되는 우리 적용 규약 `R/abs(MDD)`로 정의한다. 원문에서 정확한 산식까지 확인됐다고 주장하지 않는다. `MDD=0`이면 `undefined_zero_drawdown`으로 기록하며0이나 임의의 유한 값으로 대체하지 않는다. 다른 Calmar 정의를 추가하면 이름을 구분한다.

위험자산 노출은 실제 종가 비중 합의 일평균으로 표시하고 주문 목표 비중과 구분한다. 회전율은 각 거래일의 시가 거래 전 NAV를 분모로 한 절대 거래금액 합을 연율화하며, 위험8개와 BIL 포함9개를 각각 표시한다. 비용/NAV는 일별 비용/전일 NAV의 합을 관측월수/12로 나눈 값이다. 대체 fix-mix는 원문의12자산 구성이나 SPY/IEF60/40과 같다고 설명하지 않는다.

예측수익 상관(IC)은 다음 정의로 고정한다.

- 판단일t의 A 예측에서 자산별 `p0`와 `a_mean0/1`을 읽는다. `p0>=0.5`면 강세 평균, 아니면 해당 해석의 약세 제한을 적용한 평균을 사용한다. 하한/상한 두 해석을 같은 표에 표시한다. 현금 대피일도 배분 전 예상수익을 복원해 포함하며0으로 바꾸거나 표본에서 제외하지 않는다. 주문 비중이나 최적화 실패/대피 후의0 벡터를 예측수익으로 사용하지 않는다.
- 기본 예상수익은 같은 판단일까지의 원래 A EWMA1260 경로다. 새 표준화·추정창·하이퍼파라미터로 대체하지 않는다.
- 거래일d의 직전 거래일을t라 할 때 종가 간 진단의 실현수익은 `C_i[d]/C_i[t]-1-known_DGS3MO[d]/100/252`다. `known_DGS3MO`는 기존 자료 코드의 날짜 지연 결과다. 이 목표일 실현값을 판단일t의 입력으로 역류시키지 않는다. 가격은 모두 조정 가격이다.
- 시가 체결 이후 구간의 별도 진단은 `C_i[d]/O_i[d]-C_BIL[d]/O_BIL[d]`다. 같은 배분 전 예상수익과의 상관을 표시하되, 종가 간 수익을 목표로 만든 평균의 체결 구간 진단임을 명시한다. 거래비용 차감 계정 알파나 통계적으로 확립된 초과수익으로 부르지 않는다.
- 두 예상수익 방식은 자산·판단일·표적일이 정확히 일치해야 한다. 각 자산·기간에서 기준과 국면형 모두 같은 전체 거래일을 사용한다. 가격·피처·예상수익 결측은 중단하고 유리한 쌍만 남기는 pairwise 삭제를 하지 않는다.
- 각 자산의 Pearson 상관을 보고한다. 예측 또는 실현수익의 분산이0이면 `not_estimable_constant`와 유효 관측 수를 기록한다. 상관0으로 대체하지 않는다. 요약은 정의된 자산별 상관의 단순 평균과 자산 수/제외 사유를 함께 표시한다. 원문 `Overall`의 집계 정의가 확인되지 않으면 같은 지표라고 부르지 않는다.

전체51개월을 기본으로, 원문 표본과 겹치는2021-07–2023-12의30개월과 표본 이후2024-01–2025-09의21개월도 정해진 구분으로 함께 보고한다. 구간별 통계는 원래 전체 계정의 일별 순수익을 잘라 초기값1로 재기준화해 계산한다. 구간 시작 때 보유분을 BIL로 초기화하거나 거래 경로를 재실행하지 않는다. 구간 전 고점은 구간 MDD에 섞지 않고 연율화의 분모는 해당 구간의 관측월수/12다. 유리한 기간만 본문에 남기지 않는다.

대표 신호 그래프의 자산은 원문 예시와 대응되는 SPY·IYR·IEF로 고정하고, 전체8개도 연결 산출물로 제공한다. IEF의 종합채권 대체를 표시한다. 새 성과를 보고 가장 잘된 자산·구간을 대표로 고르지 않는다.

### 5.2 관찰된 개선과 통계적 판별을 구분한다

- 각 MV·MinVar·EW에 대해 `delta_R=R_국면형-R_기본`, `delta_S=S_국면형-S_기본`, `delta_DD=MDD_국면형-MDD_기본`을 반올림 전 값으로 산출한다. 각 차이는1e-10 초과면 개선, −1e-10 미만이면 악화, 그 사이는 수치상 동일이다. 이 허용폭은 수치 오차 구분이며 경제적 최소 효과나 유의성 문턱이 아니다. 정의되지 않은 지표는 판정하지 않는다.
- 세 지표가 모두 개선이면 해당 배분에 한해 ‘수익·샤프·낙폭의 개선 방향 유지’라고 적는다. 샤프·낙폭만 개선이면 그 두 지표에 한정하고, 다른 조합도 각 방향을 그대로 표시한다. 낙폭 감소만으로 위험조정성과 우위라고 부르지 않는다.
- MV·MinVar·EW 모두에서 세 지표가 개선될 때만 이 표본·설정에서 ‘원문 표6과 같은 개선 방향이 전체적으로 유지됐다’고 설명한다. 일부 배분에서만 개선되면 해당 배분에 한정한다. MV 약세 평균 상한/하한 해석에 따라 방향이 다르면 해석별로 보고하고 전체 유지 판정은 하지 않는다. 모든 개별 ETF가 이겨야 한다는 별도 성공 문턱은 추가하지 않는다.
- 관찰된 성과 개선은 통계적으로 확립된 우위나 미래의 재현성과 다르다. 원문 지수 표본과 ETF 표본의 수치 차이에 직접 유의성 검정을 하지 않는다. 새 진단이나 관찰된 개선을 유의성 확보로 포장하지 않는다.
- B51과 F141의 세 CER 비교는 기존 결과·가족별 동시 구간·사전 고정 기록을 그대로 유지한다. CER는 월 순수익으로 `12*mean(r)-(5/2)*12*var(r, ddof=1)`이다. 월 쌍체 원형 블록20,000회, 기본6개월·3/12개월 민감도, 세 비교 max-T 동시95% 구간이다. 두 기간의6개 대비 전체나 새 진단 전체에 대한 동시95% 보정이라고 부르지 않는다.
- D51의30개 계정은 설명용 진단이다. 기준 대비 CER·샤프·회전율·비용·노출 차이와 예측 지표를 전부 표로 제시하며 새 유의성·우승 판정을 하지 않는다. 추가 검정이 필요하면 대비 전체와 보정 범위를 새 계약에 먼저 명시해야 하며 현재 목록에 자동 추가하지 않는다.
- 분류 성능의 직접 비교는 같은 표적·평가 라벨 모델 ID를 공유하는 경로에 한정한다. 월 가중 정확도·로그손실·상태 변화일 성능·확률 분포를 보고 학습 손실과 표본 밖 손실을 구분한다. S01/P01처럼 평가 라벨도 달라지면 각자의 라벨 안에서 빈도/상태 유지 기준과 비교한다. 분류 지표용 기준 예측은 추가 투자 계정이나 독립 표본으로 세지 않는다. 과적합·과소적합·잘못된 확률 추정을 저장된 지표 없이 원인으로 확정하지 않는다.
- 연 CER0.50%p의 조건부 검정력·분산 불확실성과 전체 재학습 불확실성 미포함을 유지한다. 경로 부트스트랩은 이전 결과 열람 및 후속 설계 선택의 불확실성을 제거하지 않는다. 우위 미확인은 동등성이나 무효과의 증거가 아니다.

## 6. 코드·산출물·보고서 변경 경계

- 원자료·빈티지·캘린더와 검증된 체결/NAV 코드를 유지한다. 데이터·수치 오류가 확인되면3절의 수정 절차를 따른다.
- 기존 금융 계산 소스와 계약은 그대로 보존한다. 특히 F141 계약은 기존 `cli.py`도 해시로 잠그므로 진단용 진입점은 별도 모듈로 추가하고 기존 CLI를 무심코 변경하지 않는다.
- 새 실행 설정에는 `reference_id`, `effect_type`, `override_fields`, 고정 라벨/튜닝/평활 해시와 허용한 파생 변경 목록을 둔다. 일반 일요인 비교는 선언한 한 항목만 다를 수 있다. F08·P01 등 명시한 묶음은 예외 목록 전체를 검사한다.
- 학습 캐시에는 실제 학습창·입력 순서·가중치와 사전확률 정책·전체 XGB resolved config·JM/라벨 버전·학습 자료의 당시 가용 부분 해시를 포함한다. 배분만 바꾸는 실험은 같은 예측을 공유한다.
- 예측에는 판단/표적/가용시점·자산·정의·모형·확률·학습 범위·라벨 모델 ID·선택 경로 ID를, 거래/NAV에는 신호/체결시점·주문 방식·실제 수량/비중·드리프트·비용·회계 항목을 기록한다.
- 새 결과는 `results/redesign/`에 격리한다. 기존 `results/study/`, `results/followup/`에 새 금융 값을 덮어쓰지 않는다.
- 보고서는 원문 대응표→A51→B51→D51→F141→자료/검증/재현 순서다. 기본 README는 명시적인 프로젝트 보고 명령으로 생성하며 후속 파일 존재 여부가 선택을 바꾸지 않게 한다.
- 보고 코드·README를 바꾸면 기존 두 보고서의 표시 해시와 산출물 봉인도 재검사한다. 표시 변경과 금융 값 불변 증거를 따로 기록한다. 실제 원자료 검증의 소스 해시·시각·결과를 표시 수정만으로 갱신하지 않는다.

## 7. 실행 전·후 통과 조건

원문형 표·그래프를 만드는 `report_analysis_contract`와 새 계정을 만드는 `diagnostic_execution_contract`를 구분한다. 전자는 새 IC·Calmar·구간별 통계·개선 판정의 코드와 식, 입력 해시, 두 약세 해석, 날짜 연결, 미정의 처리, 출력 목록을 계산 전에 커밋한다. 기존 결과 열람 여부는 참으로 기록한다. 단순 기존 수치 열람과 새 성과 지표 계산을 혼동하지 않는다. 첫 보고를 위해 새 계정30개를 먼저 실행할 필요는 없다.

1. 원문 대응표, 펼친 기준 설정, 위30개 ID와 대비/묶음/파생 변경 목록을 기계가 읽는 명세로 만들고 중복·미정값·예산 초과·암묵적 변형이 없는지 검사한다. 새 진단 코드·계약을 성과 계산 전에 커밋한다. 현재 문서는 그 실행 계약을 대신하지 않는다.
2. 새 실행기의 A0 호환 경로를 기존 예측·목표·전체 NAV와 비교한다. 재사용 파일은 정확한 해시 일치, 재계산 확률은 절대오차1e-12 이내, NAV는 절대/상대오차1e-9 이내이며 라벨·선택·거래 결정은 같아야 한다. 허용오차를 사후 확대하지 않는다.
3. 대표 경계2021-06-30·2023-12-29·2025-06-30에서 새로운 학습 경로마다8개 자산을 캐시 없이 재적합한다. 새로운 선택 정책의 모든 벌점 선택도 독립 재계산한다.
4. 미래 가격·시장 입력·빈티지·미발표 라벨을 교란해 이전 피처·학습·평활·튜닝·예측·거래가 유지되는지 확인한다. JM 클래스 이름과 재학습 경계 평활의 연속성도 검사한다.
5. 모든 신규 계정을 별도의 수량 회계로 전체 재생하고 확률 합·시점·비용·드리프트·NAV 항등식을 검사한다. 최적화 계정은 대표 세 시점의 목적값 상한도 독립 확인한다. 실패·해시 불일치·자료 결측은 중단한다.
6. 모든30개 ID의 생성 또는 검증된 재사용, 원자료 검증 기록, 산출물 명세·복원 검사, 원자료 없이 가능한 공개 CI 통과를 확인한 뒤 프로젝트 보고서를 갱신한다.

표·그래프 생성에서는 IC의 날짜 정렬, 현금 대피일 처리, 상수 예측/낙폭0, 구간 재기준화, 표시 반올림과 판정 분리, 지표 식과 기존 저장 값의 일치를 독립적으로 검사한다.

작업 순서는 원문 준수 감사→보고 분석 계약/코드 고정→A51 표4/표6형 비교·NAV/낙폭·IC 검증과 첫 보고→B51 통제 비교→D51 실행 계약 고정/진단/검증→전체 보고다. 첫 보고는 실제로 완료한 범위를 표시하고, D51을 끝내기 전에 전체 재구성 완료라고 부르지 않는다.

완료는 원문과의 차이가 추적되고 주장과 증거가 일치하며 실제 자료로 재현 가능한 상태다. 원문과 같은 우위·양의 수익·유의성 확보를 완료 조건으로 삼지 않는다.
