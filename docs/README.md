# 문서 안내

현재 연구의 순서는 [레포 README](../README.md) → [결과와 부록](four_regime_results.md) → [실행 계약](four_regime_preregistration.md) → [데이터 사전](four_regime_data.md)이다.

`four_regime_research_plan.md`와 `four_regime_redesign.md`는 자료 감사 이전 논의안이다. 실제 실행한 날짜·피처·발표 시점 규칙은 실행 계약과 `configs/four_regime.json`이 우선한다. 계획에서 변경한 이유도 결과 전에 실행 계약에 기록했다.

그 밖의 기존 요인 회귀·수익률 예측 문서는 이전 연구 기록이며, 현재 네 국면 실증의 결론으로 재사용하지 않는다. 공개 소스와 로컬 실행 커밋의 동일 트리는 `source_mirrors.json`에 기록한다.
