# 실행 기록

날짜는 사용자 시간대인 Asia/Seoul 기준이다.

1. 2026-10-18: 기존 작업 트리가 깨끗함을 확인. 기존 HEAD `601419496ec5a06273e884b3edab557e746e9902`를 `legacy-korean-study-20261018` 태그로 보존했다. 기존 비추적 원자료·런타임을 포함한 파일은 로컬 형제 폴더 `dynamic-legacy-20261018`에 보존했다.
2. Python 3.12 환경, 저자 Jump 코드 커밋, scikit-learn·XGBoost·CVXPY/OSQP 의존성을 잠갔다. macOS 런타임 호환성 때문에 성과 계산 전 XGBoost 2.1.4를 선택했다. 분류기 용량·탐색 범위는 변경하지 않았다.
3. ETF 일별 원 응답·분배금·분할, FRED 일별 자료, INDPRO·CPIAUCSL의 공개 ALFRED 빈티지를 다운로드했다. URL·시각·SHA-256을 보존했다.
4. 최초 153개월 감사는 CPI 2025-10 결측으로 중단됐다. 월을 압축하지 않은 3개월 대 3개월 정의에서 2025-10–2026-03 라벨이 결측임을 확인했다. BLS 공식 설명과 대조한 후 사용자가 주 평가 2014-01–2025-09, 연속 141개월을 명시적으로 확정했다. 아직 성과 계산 전이었다.
5. 수정 감사가 통과했다. 원자료 매니페스트·141개 평가월·모형·배분·비용·주 대비·민감도를 커밋 `7844d68`에서 고정했다. `performance_computed: false`는 이 동결 시점의 상태이며 이후 결과 상태와 구별한다.
6. 순차 실행 전후의 구현 수선은 월 가중치를 표적월 기준으로 맞추기, BIL 비교 경로 추가, 동일 적합의 캐시 재사용, 입력 모멘텀을 두 자료 각각의 최신 가용 관측월과 일치시키기였다. 경제 라벨은 계속 첫 공동 완성 판에 고정한다. 영향을 받는 분류기 예측·검증은 다시 계산했다. 결과에 따라 설정·기간·대비·부록을 선택하지 않았다.
7. 거래·확률·Jump 순방향성·경제 라벨 고정·최적화·월별 부트스트랩·스냅샷 변조 단위검사 11개가 통과했다. 0/1 거래의 비용 후 NAV는 동일 자기금융 식의 닫힌 해로 계산 시간을 줄였고 독립 근 찾기와 대조했다. 외부 거래일 라이브러리의 NumPy 시간 단위 deprecation 경고가 있으며 검사 실패는 아니었다.
8. 같은 평균분산 문제를 Cholesky 인자를 이용한 CVXPY DPP 형태로 바꿔 반복 컴파일을 줄였다. 100개 시험 문제에서 원래 이차형식과 비중 최대 차이는 약 4.3e-13이었다. 일반 거래 비용도 같은 절댓값 식의 구간별 선형 해를 사용하고 독립 근 찾기와 대조했다. 정보·모형·배분 파라미터는 바꾸지 않았다. 검정력 분산 범위의 Bartlett HAC는 모든 시차에 표본수 n을 분모로 사용해 양의 준정부호 커널을 유지하도록 수선했다.

9. `3bd48f7`에서 고정 설정의 전체 주 분석·민감도 실행을 완료했다. 대표 세 시점 48개 자산/정의 재학습(분류기 96개), 미래 가격·시장자료·빈티지·미발표 라벨 교란, 전체 71개 거래 경로의 독립 재생이 통과했다. 결과 확인 후 기간·설정·주 비교를 변경하지 않았다.
10. 실행 후 후보 적합의 단일 클래스 대체 집계와 후처리 소스 기록을 보강했다. 정확한 모형/자료/프로토콜 해시가 가리키는 캐시만 사용하고 선택된 배분용 적합과 대조한다. 예측·비중·NAV·추론 수치를 바꾸지 않았다. 원래 실행 커밋과 소스 해시는 보존한다.
