# 실제 데이터 연구 사전 고정 기록

- 고정일: 2026-10-18 (Asia/Seoul). 첫 실증 회귀·OOS 결과를 보기 전 설정을 고정한다.
- 연구 ID: `kr-etf-macro-20261018-v3`. v1은 H10의 일별 관측/주별 공개 구분이 부족해 실행 도중 폐기했다. v2는 등록 후 실행 전에 H15의 다음 미국 영업일 공개도 보수적으로 반영하기 위해 폐기했다. 숫자 결과를 열람해 성과에 따라 변경한 것이 아니다. 실증 연구 자체는 과거 자료를 이용한 **탐색 연구**다. 해시 등록이 과거 자료를 한 번도 보지 않았다는 증거나 독립적인 확인 표본을 뜻하지 않는다.
- 사용자가 요구한 범위: P0–P4, P5 국면·자산배분, P6 LightGBM·SHAP, 실제 결과를 반영한 README와 GitHub 공개.
- 합성 자료는 단위 테스트의 경계조건 검증에만 사용한다. 실증 결과·검정력·투자 성과의 근거로 사용하지 않는다.

## 표본과 데이터 선택

- 공통 실제 일별 자료: 2009-07-29부터 2026-10-16까지 4,240 거래 세션. 진행 중인 2026년 10월은 월간 분석에서 제외한다.
- 분석 자산: KODEX 200(069500), KODEX 국고채3년(114260). 원화 시장 종가와 배당락일 분배금을 사용해 `(종가_t + 분배금_t) / 종가_(t-1) - 1`을 계산한다. 운용보수는 ETF 가격에 내재하고 투자자 세금은 제외한다.
- 원래 선호 대상인 장기 KOSPI200 TR·국고채 TR 지수의 공개 원본을 확보하지 못했다. 실제 상장 ETF 총수익률 프록시를 쓰며, ETF 상장 전으로 소급하지 않는다. 채권 금리 변화로 채권 수익률을 대체하지 않는다.
- 사용권 관리: 개인 비상업 연구의 원본 통계·모형 결과만 공개한다. 공급자 가격·분배금 시계열, 원본 XLS, 원자료를 복원할 수 있는 피처 패널은 로컬에 보관한다. 공개 접근을 원자료 재배포 허가로 해석하지 않는다.
- 운용사 원본 XLS 종가는 외부 서비스와 일치한다. 분배금 자료는 최근 운용사 기록과 대조하고, 외부 서비스에 없는 114260의 2025-12-12 배당락 807원(기준일 12/15, 지급일 12/17)을 보완했다.
- 계산기 수익률 API 경로는 독립된 공식 차트와 불일치해 사용하지 않는다. 분석용 총수익률을 공식 NAV 재투자 수익률 차트와 비교할 때 시장가/NAV 차이를 허용하는 누적 3% 검증 범위를 사전에 적용했다. 실제 최대 차이는 주식 약 0.53%, 채권 약 0.94%다. 가격/NAV 프록시 간 차이를 오류 없는 동일 지수라고 주장하지 않는다.

## 정보시점과 빈티지

- 의사결정: 두 ETF 원본에 공통으로 있는 월말 마지막 거래일 18:00 KST.
- 국내 월간 지표: 관측월 + 2개월 첫날부터 피처 사용을 허용한다. 이는 보수적인 **모형상 가용 가정**이다. 미확인 실제 발표시각은 `null`, 빈티지 ID도 `null`로 보존한다.
- 미국 H15 금리: 참조일의 다음 미국 영업일에 공개될 수 있으므로 **7일 버퍼**. H10 환율·달러: 일별 관측이지만 전주 자료를 다음 월요일 16:15 ET(휴일이면 다음 영업일)에 공개하므로 **14일 버퍼**. 미국 변수의 월말 동시 설명용 원천은 별도 ID로 분리해 예측에 넣지 않는다. [연준 H10](https://www.federalreserve.gov/releases/h10/), [H15](https://www.federalreserve.gov/releases/h15/), [DGS10 참조일/갱신일](https://fred.stlouisfed.org/series/DGS10)을 확인했다. 버퍼는 실제 과거 수신시각 복원이 아니다.
- **모든 실증 예측은 수정치 기반 pseudo-OOS**다. 시차를 줬다고 수정치 편향이 제거되거나 실제 투자 당시 자료가 복원된 것은 아니다.
- 현금 수익률: OECD/FRED 3개월 인터뱅크 연율을 ACT/365 단리로 환산한 비교용 프록시다. 실현 CD 수익률이나 무위험 수익률이 아니다. 포트폴리오의 현금 대기 규칙은 사용하지 않는다.

## 사전 고정 분석

- 주 타깃: 다음 달 주식–국채 상대수익률. 주 분석 피처 6개: 한국 산업생산 YoY, 한국 단기·장기 금리 bp 변화, 미국 10년 금리 bp 변화, 원/달러 변화율, 미국 광의 달러 변화율.
- CPI 기본 시리즈는 2023-11 이후 갱신되지 않아 주 분석의 2024–2026 표본을 버리지 않는다. CPI는 사전 고정한 짧은 표본의 **보조 민감도 분석**으로만 추가한다. 서로 다른 정의의 CPI를 임의로 이어 붙이지 않는다.
- 설명 분석: 주식/국채 각각 국내 대 국내+대외 모형, 동일 기간·결측 마스크. HAC Bartlett lag 3, `n/(n-k)` 보정. 대외 계수군 공동 Wald 두 검정에 Holm 보정. 조정 R²와 효과크기·신뢰구간도 보고한다.
- 시변성: 60개월 기본, 48·84개월 민감도. 달력 창 안의 결측·자유도 부족·공선성은 추정 불가로 표시한다. 원단위·창별 표준화 계수와 점별 구간을 보존한다. 구조변화 검정으로 해석하지 않는다.
- 예측: 초기 96개월, 고정 OOS 판단월 2017-08–2026-08(109개월). 평균·AR(1)·OLS·Ridge와 동일 타깃·정보시점·평가월을 쓴다. 정규화·Ridge 후보 4개 선택은 학습 창 내부에서만 수행한다.
- 초기 학습 96개월은 6피처 회귀에서 89 잔차 자유도를 확보하고 OOS를 109개월 남기는 선택이다. 표본 수만으로 검정력을 보장하지 않는다. 초기 120개월 조건은 공통 OOS에서 같은 expanding 학습을 사용하므로, 그 이후 결과가 다른 독립 검증인 것처럼 중복 주장하지 않는다.
- 예측 불확실성: 짝지은 원형 블록 부트스트랩 5,000회, 기본 6개월·민감도 3/12개월. 평균 대비 4개 비교의 동시 구간은 Bonferroni. 이는 실현된 손실 경로에 조건부인 기술적 구간이며, 중첩·규제 모형에 동일한 DM p-value를 기계적으로 붙이지 않는다.
- 검정력: H1은 효과크기별 비중심 χ² 근사와 잔차 의존성에 따른 유효표본 민감도를 보고한다. OOS는 짝지은 손실 변동성에 근거한 최소 탐지 효과를 제시한다. 비유의를 효과 부재의 입증으로 해석하지 않는다.

## 부록 계약

- P5: SAA 50/50, 수익률 피처 3개의 NON_MACRO, 동일 절차에 거시 6개만 더한 MACRO_TAA. 12개월 위험 피처 워밍업 후 최소 학습 84개월, 두 동적 전략에 같은 Ridge 후보·내부 검증·30–70% 주식 제약·정책함수·OOS·비용 적용.
- 신호는 월말 18시에 고정하고 그 뒤 첫 공동 양(+)의 거래량 세션 종가에 체결한다. 새 비중은 그 종가 이후 수익에만 적용한다. 판단에서 체결까지 갭은 기존 비중이 보유한다.
- 체결 직전 드리프트 비중에서 실제 거래금액과 비용을 계산하고, 비용을 낸 후 목표 비중을 충족하는 자기금융 NAV 방정식을 푼다. 초기 계정은 모든 전략에 50/50으로 동일하게 부여한다. 마지막은 다음 체결일 종가 평가이며 청산매도 비용을 임의로 생략한 실현수익이라고 주장하지 않는다.
- 기본 편도 비용 10bp, 민감도 0·5·25bp. 비용은 매수+매도 총거래금액에 적용하고 편도 회전율은 그 절반으로 정의한다. 분배금 재투자 거래에도 비용을 반영한다.
- 배당락일 종가 재투자는 이론적 TR 관행이다. 지급일까지의 미수금·현금 결제 지연을 완전히 복원하지 못했으므로 **실제 ETF 자료에 근거한 이론적 체결 백테스트**로 표시한다. 실거래 체결 성과로 포장하지 않는다.
- P6: 공식 LightGBM 4.6.0 C++ CLI. 같은 주 타깃·6개 피처·109개월 OOS. 작은 트리·정규화·내부 3개 시계열 origin과 6개월 검증 블록, 4후보. OOS TreeSHAP만 저장하며 합계=예측값을 검증한다. 통화 피처 둘의 제거 실험은 사전에 고정하고 결과를 보고 주 피처를 바꾸지 않는다.
- 국면은 연속형 신호에서 주식 비중 45% 미만/45–55%/55% 초과로 기술한다. 표본 수가 작거나 비어 있으면 그대로 표시한다. 성장×물가 4분면을 강제하지 않는다.

## 변경과 실패

- 설정 변경은 새 실험 ID로 등록한다. 해시가 달라진 기존 ID는 실행을 차단한다.
- 실패한 실제 실행도 원장에 남긴다. 사후 성과에 유리하게 평가월을 줄이거나 부록 결과를 숨기지 않는다.
- 원본 자료·현재 빈티지·ETF 프록시·표본의 한계가 있으므로 이 연구를 원래의 장기 지수/실시간 빈티지 MVP와 동일한 완료로 표시하지 않는다. 요청한 분석 단계 전체를 실제 자료의 가용 범위에서 수행한다.
