## 해석의 경계

- 전 기간 위험 보유·거래가 정확히0인 BIL 단독 계정은 미세한 회계 반올림 오차를 검증한 뒤 초과수익/변동성0·샤프 미정의로 표시한다. 원래 부동소수점 값은 CSV 별도 열에 남긴다. NAV·CER는 바꾸지 않는다.
- XGB 원시 이진 확률의 float32 합 오차는 해당 정밀도 이내인지 검사하고, 표본 밖 원시 로그손실만 p1=1-p0로 계산한다. 원시 파일은 보존한다. 학습 손실은 원래 float32, 표본 밖 손실은 float64 계산이라는 정밀도 차이를 명시한다.
- F01은 분류기 학습만5년이다. P01은 JM·분류기·평균 이력과 선택 경로가 함께 바뀌고 공분산11년·검증5년을 유지한다.
- F03/F04·I01은 사전확률을 A 기준으로 고정하고 학습손실의 상대 월 비중·절대 가중치 크기·L2를 나눈다. min_child_weight 등의 다른 절대 문턱 상호작용을 모두 설명하지는 않는다.
- M02는 일별252개 축소만, M03은 평균 월 가중만, M04는 BIL 기준만 바꾼다. 기존 묶음 축소와 구분한다.
- M06은 현금 규칙을 뺀 M05와 위험회피10·거래벌점1이 같고, 예상수익만 무국면 EWMA로 바꾼다. 강약세 마스크와 약세 제한을 사용하지 않는다.
- post_open_risk_exposure는 NAV 원장의 체결 직후 실제 위험비중이며, HOLD일의 판단 시점 제안 비중과 다르다. 실제 종가 노출은 별도 열이다.
- T04는 강제 현금→신호 종가 상한 위반→L1 2% 미만 수량 유지의 순서다. HOLD-UNITS는 다음 시가에 과거 비중으로 재조정하지 않는다.
- A0/T01/T02/T03, F03/F04/I01 두 행, 국면별 B/I02 세 행의2×2를 각각 읽는다. 단일 차이를 더해 원문 대비 전체 차이의 설명 비율로 해석하지 않는다.
- S01/P01은 평가 라벨 경로도 달라진다. 정확도·로그손실은 자신의 빈도·유지 기준과 읽으며 서로 다른 국면의 정확도를 직접 우열 비교하지 않는다.
