# 4국면 연구 실행 계약

2026-10-18 v2. 최초 4국면 결과를 이미 관찰했다. 기존 201/115개월 비교 규칙을 유지한 상태로 불필요한 이전 연구를 제거하고, 별도 검정력 확대 실험 전에 새 실행 계약을 등록했다. 이번 실행은 역사적 재분석이다. 과거 연구에서 한국 ETF 수익을 이미 관찰했으므로 독립 미열람 확인연구가 아니다. 계획의 성과 목표를 달성하지 못해도 정의·기간·비교군을 바꾸지 않는다.

- 주 분석: OECD 333개 월별 아카이브(1999-02–2026-10). 주 예측 판단월 2009-09–2026-05, 주 배분 판단월 2016-11–2026-05. 초기 분류 학습 120개·국면별 12개, 배분에 가용한 완성 수익/라벨 84개라는 **자료 기준만으로** 날짜를 정했다. 1판 추가 지연 민감도도 같은 월에 최소 학습량과 확정 라벨을 충족하도록 시작·끝을 공통으로 맞췄다. 기본안만 보면 2009-06/2016-10부터 가능하지만 공통 비교를 위해 뒤로 미뤘다.
- 보조 장기 분석: 1990-01부터의 지수와 1991-01부터의 국내 금리, 1991-08부터의 입력 사례. 120개월 워밍업 후 2001-10–2026-07 예측. 상장 전 ETF 수익은 만들지 않는다.
- 최신 수정치와 아카이브를 비교할 때 `REVISED_MATCHED`는 아카이브에 실제 존재했던 관측월 마스크와 라벨 가용일을 유지하고 값만 최신치로 바꾼다. 이 모드의 라벨도 최신 정의이므로 성과차를 순수한 인과적 빈티지 효과로 해석하지 않는다. 동일 타깃 라벨 교차 채점도 별도 제공한다.
- 첫 공동 완성 아카이브를 라벨로 삼는다. 아카이브 판의 정확한 과거 배포시각은 확인하지 못했다. 판의 다음 달 1일 00시 KST부터 사용한다는 가정을 두고, 한 판 더 지연하는 민감도를 수행한다. 국가기관의 실제 최초 발표본과 같다고 주장하지 않는다.
- 평가 대상은 `study_asof`까지 위 가정상 가용해진 라벨만이다. 공통 평가 끝인 2026-05 이후 판단의 미완성 국면 예측과 체결 수익은 잠정 출력이며 주 점수에 섞지 않는다.
- 학습 라벨, 내부 검증 라벨, 정책 학습 수익 각각의 가용일을 검사한다. 미래 라벨이 있으면 실행을 실패시킨다. 원천의 결측·빈티지를 임의 보간하지 않는다.
- 전체 표본 정규화·라벨 분위수·양방향 필터·랜덤 CV·SMOTE·성과 기준 국면 병합을 금지한다. 로지스틱의 표준화는 매 학습 창에만 적합한다. LightGBM은 정규화가 필요 없는 원 피처를 사용한다.
- LOGIT과 LGBM은 같은 정보·타깃·훈련 행·24개 내부 origin을 사용한다. 기본 후보 각 4개와 온도 3개를 내부 OOF 로그손실로 공동 선택한다. MARKOV의 온도도 같은 내부 origin에서만 고른다. 모델별 자유 탐색을 하지 않는다.
- 4상태 전이는 최신 가용 국면에서 목표월까지 필요한 횟수만큼 진행한다. 최초 가용 라벨 이력과 현재 빈티지의 최신 상태를 사용한다.
- 각 cutoff에서 라벨과 체결 수익이 모두 알려진 행만으로 조건부 평균을 학습한다. 최근 완성 60개월 공분산과 24개월 평균 수축을 공유한다. 국면 모델들에 동일한 4개 정책 비중을 적용한다.
- 기본 비용 편도 10bp, 주식 30–70%, 나머지 국채. 신호 뒤 첫 실제 공동 거래 세션 종가에 체결한다. 다음 신호 체결 전까지의 갭은 기존 보유분이 부담한다. 배당락일 종가 재투자와 종가 체결은 이론적 가정이다.
- 주 비교는 LOGIT−MARKOV, LGBM−MARKOV, LGBM−LOGIT 각각의 로그손실 개선과 비용 차감 연 CER 개선이다. **6개 전체에 Bonferroni 95% 동시 구간**, 20,000회 짝지은 원형 블록(6개월), 3/12개월 민감도를 고정한다. 보조 분석에서 나온 유리한 숫자를 주 결과로 올리지 않는다.
- 설계 검정력은 최초 OOS 이전의 내부 OOF 예측 24개월, 배분 시작 전 24개월의 개발 수익 경로에 근거한 HAC(6) 근사 MDE다. 개발 구간은 후보 0·T=1로 고정한다. 미래 OOS 효과 크기로 충분한 검정력을 역산하지 않는다. 작은 개발 표본의 분산 추정도 불안정하므로 보장으로 해석하지 않는다.
- 1/6개월 평활, 국내/대외 입력 제거, 1판 추가 지연, 수정치 비교, 비용 0/5/25bp, 정책 gamma 2/10, 평균 수축 12/48개월을 전부 보고한다. 정책 gamma 민감도에도 평가지표 CER의 gamma는 5로 고정한다. 각 민감도는 사전 고정한 주 평가월을 유지하며 최소 학습 조건이 불충족하면 실패 사유를 공개한다.
- 전환의 탐지 지연은 새로운 실제 국면 에피소드 안에서 첫 정답 argmax까지의 개월 수다. 끝까지 맞추지 못하면 null이다. 오경보는 실제 국면이 유지되는데 예측 argmax가 바뀐 달이다. 사후 진단이며 실시간 매매 신호의 검정이 아니다.
- SHAP은 4개 클래스의 raw score별 합산을 검사한다. 온도/softmax 이후 확률에 기여가 선형 가산된다고 해석하지 않는다.

## 초안에서 바뀐 항목과 근거

모두 신규 모델 결과를 보기 전 데이터 감사에서 변경했다.

1. 장기 금리가 2000-10에 시작해 거시 표본을 자르므로 주 피처를 한국 단기금리의 3개월 bp 변화로 교체했다. 장기 표본 보존을 위한 자료 선택이며 예측 성과에 따른 선택이 아니다.
2. 월말 마지막 거래일 대신 달력 월말 18시를 사용한다. 1991년까지 동일한 한국 거래일 원본을 확보하지 못했으며 주말 판단도 허용하는 월간 연구로 통일했다. 체결은 여전히 다음 실제 세션이다.
3. WTI 원자료에 2020년 음수가 있으므로 원유 변화율을 고정 스케일 50달러의 asinh 변화로 바꿨다. 음수 삭제·임의 보간·전체 표본 winsorization을 하지 않는다.
4. 아카이브 333개를 실제 확보해 최신 수정치 장기 분석보다 아카이브 분석을 주 비교로 승격했다. 아카이브 판 가용일은 가정이며 모든 시장통제변수의 역사 빈티지를 확보한 것은 아니다.

## 남는 편향과 확인 연구의 조건

과거 ETF 결과를 이미 봤다는 연구자 선택의 영향, OECD 아카이브와 실제 수신시각 차이, 최신치인 금리·환율·원유 통제변수의 개정, ETF 두 종목과 한국 한 국가의 범위 제한, 월별 손실 의존성, 하나의 역사 경로에서의 모델 선택 불확실성이 남는다. 관련 감사표·민감도·시간별 결과를 공개한다. ‘편향 완전 제거’나 ‘과적합 없음’이라는 문구를 결과에 쓰지 않는다.

전향 확인은 실제 향후 cutoff에 입력 해시·확률·비중을 보존한 뒤 발표되는 라벨과 수익으로 해야 한다. 역사 자료를 다시 나눈 구간을 새로 수집한 미열람 전향 표본으로 부르지 않는다. 이 연구는 자동화나 실거래 주문을 만들지 않는다.

## v2 변경 기록

- 이전 팩터 연구 코드·데모·설정·문서·산출물을 현재 트리에서 제거했다. Git 이력을 독립 미열람의 근거로 사용하지 않는다.
- 정책 민감도의 gamma/shrink 인자가 정책 계산에 전달되지 않던 오류를 수정했다. 주 분석의 기본값 5/24에는 영향이 없다. 수정된 민감도를 전부 재계산한다.
- 별도 [검정력 재시도 계약](power_retry_protocol.md)에 확대 기간·학습 조건·가족 12개 보정·분산 민감도를 고정했다.
- 추가 지연 민감도는 라벨 가용성상 200개월(2026-04까지)만 채점된다. D1은 기존 발견 기록으로 보존하며, 이번 실행에서도 동일 200개월 마스크를 명시한다. 주 비교 201/115개월을 변경하지 않는다.
