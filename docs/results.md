## 분류와 입력

선택된 배분용 분류기의 단일 클래스 빈도 대체는 0/768회다. 별도로, Jump 벌점 후보의 실제 분류기 적합 2,400회 중 대체는 0회이며, 후속 검증 창에 사용된 적합은 2,320회다. 선택된 2국면 적합은 후보 적합의 부분집합이므로 횟수를 더하지 않는다. [후보별 기록](../results/main/candidate_fits.csv)과 [6개월 부록 집계](../results/macro6/candidate_fit_audit.json)를 공개한다. [정의별·자산별 분류 성능](../results/main/classification.csv)에서 빈도·국면 유지와 비교한다. 2국면과 4국면 손실을 직접 비교하지 않는다. [입력 기여도](../results/main/input_importance.csv)는 로지스틱 절대 표준화 계수와 XGB 분할 중요도의 블록 내 정규화 요약이다. 인과효과나 모형 간 공통 척도가 아니다.
