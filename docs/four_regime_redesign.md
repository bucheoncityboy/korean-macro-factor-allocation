# 성장·물가 4국면 예측과 자산배분 — 개편 설계 초안

- 작성일: 2026-10-18 KST.
- 사용자 확정 사항: 국면은 골디락스·오버히트·리세션·스태그플레이션의 **4개**로 고정한다. 기존의 2국면 시작 제안은 적용하지 않는다.
- ‘리그레션’은 문맥상 경기 후퇴를 뜻하는 **리세션(Recession)**으로 해석했다.
- 상태: 설계 초안. 새 4국면 모형의 실증 실행·성능 검증·GitHub 결과 게시는 아직 하지 않았다. 기존 v3의 결과는 새 4국면 모형의 결과가 아니다.
- 기존 원자료·등록 계약·결과는 보존한다. 이 문서는 이전 등록을 소급 수정하지 않는다.
- 구체적인 수치 기본안·모형·배분·평가·검정력·실행 단계는 [연구계획 보고본](four_regime_research_plan.md)에 정리했다. 아래 내용은 최초 개편 방향 기록이다.
- 후속 사용자 의견을 반영해 **로지스틱과 LightGBM을 공동 주 비교**로 올렸다. 예측·배분 각각 세 쌍의 비교, 총 여섯 주 비교를 계획서에 반영했다.

## 확정한 국면 체계

| 내부 ID | 이름 | 성장 방향 | 인플레이션 방향 |
|---|---|---|---|
| goldilocks | 골디락스 | 개선·가속 | 둔화 |
| overheat | 오버히트 | 개선·가속 | 가속 |
| recession | 리세션 | 둔화 | 둔화 |
| stagflation | 스태그플레이션 | 둔화 | 가속 |

- 현재 초안의 두 축은 **성장과 인플레이션의 모멘텀**이다. 성장률의 플러스/마이너스, 물가 수준의 높고 낮음, CPI 지수 자체의 상승/하락과 구분한다.
- CPI 지수가 계속 오르더라도 전년동월 물가상승률이 낮아지면 인플레이션 둔화가 될 수 있다.
- 위 표의 리세션은 이 연구에서 정의하는 동반 둔화 국면의 이름이다. 공식 경기침체 판정이나 실질 GDP 감소의 동의어로 사용하지 않는다.
- 성장·물가의 상승/하락 조합으로 네 국면을 구성하는 선행 프레임워크가 있다. 본 연구는 한국 자료의 원천·변환·정보시점·예측·배분 효과를 별도로 검증해야 한다. [MSCI, Index Performance in Changing Economic Environments (2014)](https://www.msci.com/downloads/web/msci-com/research-and-insights/blog-post/what-fed-monetary-policy-has-meant-for-factors/what-fed-monetary-policy-has-meant-for-factors-Index_Performance_in_Changing_Economic_Environment.pdf).

## 수치 정의 후보 — 아직 등록하지 않음

- 성장 대표값은 산업생산 YoY를 우선 검토한다. 지표가 나타내는 범위를 ‘한국 경제 전체의 실제 성장률’로 과장하지 않는다. 월별 경기지표 대안을 함께 조사한 후 원천 하나와 변환 하나를 고정한다.
- 인플레이션 대표값은 한국 전체 CPI의 YoY다. 기존 KORCPIALLMINMEI는 2023-11 종료이므로 기존 자료만으로 2024–2026의 4국면 라벨을 만들 수 없다. 같은 정의로 계속 갱신되는 공식 원천의 장기 이력을 먼저 확보해야 한다.
- 방향 측정 후보는 각 YoY의 최근 3개월 평균에서 직전 3개월 평균을 뺀 값이다. 이는 모멘텀 후보이며, 4국면의 명칭을 확정했다고 평활·임계값까지 확정된 것은 아니다.
- 미래를 사용하는 양방향 필터·전체 표본 추세 제거·전체 표본 분위수는 라벨과 투자 피처에 사용하지 않는다. 정확히 0인 경우의 처리도 결과 확인 전에 고정한다.
- 특정 국면의 관측이 적더라도 상태를 임의로 합쳐 사용자 지정 4국면을 바꾸지 않는다. 해당 국면의 추정 불확실성과 관측·전환 횟수를 공개한다.

## 주 연구 흐름

1. **판단 시점의 입력:** 마지막 공동 거래일 18:00 KST 이전에 가용한 데이터만 결합한다. 발표시차·수정 빈티지·결측을 기록한다.
2. **다음 달 4국면 확률:** `P(S_(t+1)=k | I_t)`를 산출한다. 네 확률은 비음수이며 합이 1이어야 한다. 가장 높은 확률 하나만 기록하지 않고 전체 확률·불확실성을 저장한다.
3. **학습 라벨의 가용성:** 월이 끝났다는 이유만으로 그 달의 경기·물가 라벨이 알려졌다고 취급하지 않는다. 라벨 구성 지표가 cutoff까지 공개된 학습 사례만 사용한다. 개정 전후 라벨도 구분한다.
4. **배분:** 네 국면별 정책 비중을 `w_k`라 하면 `w_t = Σ_k p_(t+1,k) w_k`로 혼합하는 해석 가능한 정책을 주 후보로 둔다. 정책 비중은 사전 고정하거나 학습 창 내부에서만 선택한다.
5. **체결:** 신호 이후의 기존 체결·비용·드리프트 NAV 엔진을 재사용한다. 미래 국면 라벨을 확인한 뒤 그 달의 투자 비중을 바꾸지 않는다.

- 성장·물가 두 축을 따로 예측하는 모형을 비교하더라도 두 확률의 곱을 독립성 검증 없이 공동 4국면 확률이라고 단정하지 않는다.
- 공식 사후 경기순환 판정은 당시 투자자가 안 정보와 구분해야 한다. [NBER의 사후 판정 절차](https://www.nber.org/research/business-cycle-dating).

## 모형과 비교 전략

- 예측 기준: 과거 4국면 빈도, 마지막으로 가용한 국면, 평활한 4상태 Markov 전이확률. 0확률에 따른 무한 로그손실을 피하는 평활 규칙을 사전 고정한다.
- 공동 주 모형: 규제 다항 로지스틱 회귀와 native LightGBM multiclass. OOS SHAP·확률 보정·실패 분석을 주요 결과와 연결한다. 두 축 모형을 추가할 경우 공동확률 구성 가정을 별도 기록한다.
- HMM을 추가하면 해당 시점까지의 filtered 확률에서 다음 달 확률을 산출한다. 미래를 본 smoothed 확률이나 사후 상태 이름 정렬을 투자 신호로 사용하지 않는다.
- 배분 기준: 고정 50/50, 기존 수익률 기반 NON_MACRO, 마지막 가용 국면에 같은 정책을 적용한 전략, 예측 4국면 확률에 같은 정책을 적용한 전략.
- 기존 국내 주식·국채를 기본 투자 대상으로 유지한다. 현금·금 등 자산 추가 여부는 실제 수단의 TR·사용권·공통 표본을 확인한 후 별도 확정한다. 4국면을 지정한 것만으로 투자자산 확대가 확정된 것은 아니다.
- 국면별로 특정 자산이 반드시 유리하다고 가정하지 않는다. 국면별 수익·위험 분리 정도와 배분 추가 가치를 실제 자료로 검증한다.

## 평가와 검정력

- 주 예측 평가: multiclass 로그손실·Brier score와 기준 대비 짝지은 차이. 주 지표 하나와 다중비교 범위는 실행 전에 최종 등록한다.
- 진단: 국면별 precision/recall·확률 보정, 전환 탐지 지연, 전환 전후 오경보, 국면별 관측 수·독립적인 에피소드·전환 횟수. 높은 전체 정확도만으로 성공을 선언하지 않는다.
- 배분 평가: 같은 평가월·체결·비용·제약에서 순수익, 변동성, Sharpe, MDD, 회전율과 짝지은 불확실성. 예측 국면과 마지막 가용 국면의 비교가 ‘예측’의 추가 가치를 분리한다.
- 개발 자료만으로 경제적으로 의미 있는 최소 개선폭과 탐지 민감도를 먼저 평가한다. 일별 행 수나 긴 국면의 월 수를 독립적인 전환 횟수로 대체하지 않는다.
- 이미 사용한 기간은 개발·탐색 표본이다. 동일 기간을 재분할해 독립적인 미열람 확인 표본이라고 부르지 않는다. 신규 예측은 입력과 확률을 결과가 나오기 전에 저장한다.
