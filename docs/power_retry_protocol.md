# 검정력 재시도 실행 계약

2026-10-18. 기존 4국면 201/115개월 결과를 본 뒤 사용자의 검정력 재검토 요청으로 설계했다. 아래 확대 구간의 신규 모델 출력 전에 코드·원천 해시·설계를 등록한다. 독립적인 미열람 확인 연구가 아니다. 이전 팩터 연구는 현재 작업 트리에서 제거한다.

- 기존 비교는 예측 2009-09–2026-05 201개월, ETF 배분 2016-11–2026-05 115개월로 보존한다. 이를 유리한 기간으로 교체하지 않는다.
- 확대 예측은 **2006-09–2026-05 237개월**이다. 외부 최소 학습 84개(내부 최소 60+검증 24)를 허용하되, 각 실제 내부 origin의 학습 60개 이상, 외부 국면별 12개 이상을 직접 확인한다. 라벨 발표 지연 때문에 첫 적격 cutoff의 실제 외부 학습량은 87개다. 84개라는 단순 합만으로 적격 여부를 가정하지 않는다.
- 확대 배분은 **2014-10–2026-05 140개월**이다. 실제 상장 ETF만 사용한다. 공분산 60개월, 완성 수익·가용 라벨 쌍 60개 이상을 충족하는 최초 판단월이다. 기존의 84쌍 제한을 60쌍으로 낮추므로 초기 정책 추정 오차가 커질 수 있다. 이 구간의 국면별 학습 수와 비중을 공개한다.
- 4국면 정의, 입력 8개, 내부 검증 24개, 로짓/LightGBM 후보 각 4개, 온도 3개, 정규화·정규화 강도, 거래비용 10bp, 주식 범위 30–70%, 정책 gamma 5·수축 24개월은 동일하다. 같은 월의 확률은 기존 201개월 분석과 정확히 같아야 한다.
- 3쌍×2지표의 확대 비교 6개를 모두 보고한다. 기간을 추가했으므로 기존 6개와 합쳐 **12개 가족의 Bonferroni 95% 구간**을 별도 계산한다. 20,000회 짝지은 원형 블록, 기본 6개월·민감도 3/12개월. 원래 가족 6개 표는 당시 설계의 참조값으로만 남긴다.
- 실질 효과 기준은 로그손실 **0.02 nat**, 비용 차감 연 CER **0.50%p**, 유의수준 5%, 목표 검정력 80%를 유지한다. 검정력을 높이기 위해 기준을 느슨하게 바꾸지 않는다.
- 24개월 개발 표본 하나에 의존한 기존 MDE 옆에, 실제 튜닝 절차가 산출한 전체 짝지은 손실 경로·CER 영향함수의 HAC(3/6/12) 표준오차를 사용한 **고정 효과에 대한 설계 민감도**를 추가한다. 실제 관측 효과를 대입한 사후 검정력을 계산하지 않는다.
- HAC(6) MDE의 불확실성은 실제 관측 월 블록 2,000회 재표집으로 표시한다. 시장·라벨·수익의 합성 자료를 실증 증거로 만들지 않는다. 재표집은 측정 불확실성 계산일 뿐 새로운 관측 수가 아니다.
- 전체·2020년 이전·2020년 이후의 분산을 모두 보고한다. 필요 표본 N은 해당 분산이 유지된다는 가정 아래의 정규근사이며, 국가 간 독립성·장기 정상성을 보장하지 않는다. 12개 가족 기준과 같은 분산에서 기간만 늘렸을 때의 기계적 표준오차 감소도 분리한다.
- 검증: 신규 최초·위기·마지막 실제 origin 재적합, 미래 라벨 교란, 공통 월 확률 일치, 표본 누락·중복 거절, 실제 거래/NAV 경로 재생, 원천/등록/산출물 해시 검사. 결과가 불리해도 전부 공개한다.
