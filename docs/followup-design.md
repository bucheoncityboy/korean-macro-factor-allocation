# 141개월 후속 실험: 수정한 문제와 고정한 검증

이 설계는 51개월 결과를 열람하고 사용자가 개선 실행을 요청한 뒤 고정했다. 전향 검증이나 최초 사전등록으로 부르지 않는다. 원문 준거 A와 이전 통제 B의 실제 결과는 보존한다. 새 성과 계산 이전에 자료 적격성 감사·모형·배분·검정·비교군을 별도 계약으로 커밋했다.

## 공통 조건과 선택

- ETF 8개와 실제 BIL, ALFRED 산업생산·CPI 첫 완성 빈티지, FRED 한 거래일 지연, 17개 공통 피처는 유지한다. 상장 전 수익·누락 경제 라벨을 만들지 않는다.
- 자산별 Jump 벌점 후보는 0·0.1·1·10·100이다. 직전 3년의 로지스틱과 얕은 XGBoost 순 0/1 샤프 평균으로 선택한다. 같은 JM 라벨을 모든 분류기·기준 예측이 공유한다.
- 매월 학습 가중치 합은 1이다. 미관측 클래스·단일 클래스의 공통 사전확률 처리를 유지한다. 확률 평활 반감기 4일은 후보별로 최초 검증부터 재학습 경계를 이어 간다.
- 평균은 실제 BIL 초과수익, 월 가중, 12개월 상당 전체 평균 축소다. 공분산은 과거 5년 EWM252, 위험회피 10, 자산 상한 40%, 공매도·차입 금지다. 주 비교에는 강제 현금 규칙이 없다.
- 거래 비용은 모든 ETF 다리의 실제 편도 5bp다. 21일 계획기간은 평균·분산을 같은 기간으로 볼 때 목적함수의 일회성 거래 벌점이 1/21로 환산된다는 모델 가정이다. 체결비용 자체를 할인하거나 21일 예측 정확도를 주장하지 않는다.
- 신호 종가의 기존 비중이 상한을 넘으면 밴드로 보유를 지속하지 않는다. 보유 주문의 다음 시가 비중은 미리 알 수 없으므로 실제 실행 비중은 거래 로그에, 결정 당시의 주문 비중은 목표 로그에 따로 기록한다.

## 전체 결과를 남기는 규칙

주 결과는 `primary` 정책·5bp·141개월의 원래 세 대비다. `legacy`, 현금 다리 비용, 계획기간, 5% 밴드, 비용 0/10/25bp는 진단·민감도이며 최고 결과를 새 주 결과로 고르지 않는다. 실제 실행은 장기 45개와 원문 요인 24개의 69개 계정을 모두 포함한다.

24개 원문 연결 실험은 확률 혼합의 유무를 같은 조건부 평균과 약세 하한에서 비교한다. 원문 평균에서 축소 평균으로 바꾸는 비교는 현금 기준·월 가중·축소의 묶음 효과이며 한 요인의 인과효과라고 부르지 않는다. `hard_paper + cash on + legacy` 경로는 저장된 원문형 A 계정을 재생해야 한다.

주 지표는 월 순수익의 연 CER(위험회피 5), 세 대비의 동시 95% 구간은 월 쌍체 원형 블록 20,000회·기본 6개월·3/12개월 민감도로 계산한다. 여러 ETF나 월 라벨의 일별 반복으로 표본 수를 늘리지 않는다. 80% 검출 효과는 같은 경로 오차에 효과를 더한 조건부 모의값이며 미래나 전체 재학습의 검정력을 보장하지 않는다.

대표 세 경계에서 8자산 × 2정의의 48개 독립 재적합, 미래 가격·시장·경제 피처·미발표 라벨 교란, 69개 계정의 별도 주식 수량 재생, 최적화 해의 목적값 상한을 검사한다. 실패는 공개하고 중단한다. 긍정적인 성과·ML 우위·유의성은 완료 조건이 아니다.

## 실행

```bash
uv run etf-study followup audit
# 새 설계를 처음 고정할 때만 실행하고 계약과 코드를 커밋한다.
uv run etf-study followup freeze
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 uv run etf-study followup run --workers 4
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 uv run etf-study followup verify --workers 4
uv run etf-study followup report
uv run etf-study followup verify --artifacts-only
```

기존 실행을 재현할 때는 `freeze`를 생략한다. [고정 프로토콜](../configs/followup_protocol.json)과 [실행 계약](../configs/followup_contract.json)의 해시가 일치해야 한다. 이 후속 연구는 11년 학습·5년 검증의 원문 준거와 다른 설계이며, 원문 실증을 수치 재현했다고 설명하지 않는다.

## 첫 실행 중단과 수치 수정

최초 계약은 1440개 후보 적합을 완료한 뒤, 연결 실험 `a_soft_shrink_cash0/cash_cost`의 2022-10-24 최적화에서 OSQP `user_limit`으로 중단됐다. 전체 성과표는 계산·열람하지 않았다. 실패 입력의 위험 비중은 약 7×10⁻¹⁰이었다.

그 입력은 기존 비중을 일부 매도·유지하는 경계 해가 전체 문제의 KKT 조건을 만족한다. 비중을 반올림하거나 다른 전략으로 대체하지 않고, 이 조건을 엄밀히 확인하는 사전 해법을 현금 다리 포함 목적에 추가했다. 독립 지지초평면 LP의 목적값 개선 상한은 약 4.6×10⁻¹²였다. 원문의 위험 다리만 사용하는 해법은 유지했다. 연구 파라미터·목적함수·제약은 바꾸지 않았다.

[실패 입력](../results/followup/solver_failure.json), [최적성 확인](../results/followup/solver_repair.json), 최초 계약·실행·정확한 소스 번들을 보존하고 계약의 `numerical_amendment`에 해시를 연결했다. 네 예측 산출물은 해시가 같은 값을 재사용해 거래 계산을 다시 실행했다. 기본 재현 명령은 전체 예측부터 다시 생성하며, `--reuse-forecasts`는 이 기록된 수치 수정에서만 허용한다.
