# 성과 부진 원인 진단 설계

사용자의 원인 분석 요청에 따라 기존 결과를 본 뒤 수행하는 **사후 탐색 진단**이다. 6개월 평활 부록의 예측 개선과 배분 부진도 이미 확인했다. 아래 범위를 새 실행 전에 코드·설정과 함께 Git 커밋으로 고정한다. 기존 등록·주 분석·검정력 계산을 바꾸지 않으며, 이 문서는 독립 사전등록이 아니다.

- **국면의 시간 척도:** 기존 8개 시나리오를 공통 201개월에서 비교한다. 추가 지연은 기존 계약대로 200개월만 점수가 있으므로 ARCHIVE와 그 200개월에서도 비교한다. 각 정의의 과거 빈도 대비 로그손실 개선, 국면 지속기간, 최신 알려진 국면과 타깃의 간격을 함께 본다. 평활에 따라 입력과 정답이 함께 변하므로 순수한 한 요인의 인과효과로 해석하지 않는다.
- **확률 보정:** 기존 선택 후보의 보정 전·후를 동일 정답에서 비교한다. 새 모델은 기존 로지스틱·LightGBM의 4개 후보를 모두 T=1로 237개 월마다 다시 학습한다. 후보별 전체 결과와 동일 가중 확률 앙상블을 공개한다. 가장 좋은 후보를 골라 주 결과로 대체하지 않는다.
- **비교군의 이력:** 기존 과거 빈도·국면 전이는 1999년 이전 라벨도 이용할 수 있다. 두 학습모형과 동일한 학습 표적월만 쓰는 빈도·전이 비교군을 추가한다. 전이의 온도는 각 시점에 알려진 최근 24개 내부 검증월에서 기존 온도 후보만 비교한다. 전 기간 25% 확률도 함께 표시한다.
- **배분 경로:** 확대 구간 140개와 기존 6개월 평활 부록 115개를 각각 원래 정책과 실제 일별 거래 엔진으로 재생한다. 0/10bp, 50/50, LightGBM, 로지스틱, 국면 전이, POOLED를 비교한다. 원래 저장된 비중·수익률과 재생 결과의 일치를 먼저 확인한다.
- **주식 노출·타이밍·비용:** LightGBM의 전 기간 평균 목표 주식 비중을 고정한 사후 비교군을 사용한다. 연율 로그성장률 차이를 `노출(고정비중 0bp−50/50 0bp) + 타이밍(ML 0bp−고정비중 0bp) + 상대 비용`으로 정확히 분해한다. CER 차이도 같은 차분 항등식으로 확인한다. 이 사후 고정비중은 실시간 전략이 아니며 통제 실험에 의한 인과분해가 아니다. CAGR %p와 연율 로그성장률 %p를 혼용하지 않는다.
- **미래 국면을 아는 진단:** 시점별 과거 자료로 추정한 네 정책은 유지하되, 실현된 다음 달 국면에 해당하는 정책을 선택한다. 미래 정답을 이용하므로 거래할 수 없는 진단이다. 추정 정책이 부정확할 수 있어 수학적 성과 상한도 아니다. 4개 정책의 균등 혼합도 함께 공개한다.
- **국면과 수익 연결:** 확대 140개를 시간순 70/70 구간으로 고정하고 각 국면의 주식−국채 실제 보유구간 수익 차이를 모두 기록한다. 시점별 정책의 학습 수, 비중 하한·상한, 네 비중의 간격을 확인한다. 연도별 ML−50/50 로그성장 기여도도 빠짐없이 공개한다.

새 유의성 검정이나 효과의 인과 식별을 주장하지 않는다. 이 분석은 기존 경로의 취약 지점을 찾으며, 발견한 설계 변경의 효력은 미열람 기간에서 별도 확인해야 한다. OECD 판의 가용일 가정과 시장변수 최신 수정치 한계는 그대로 적용된다.
