# 한국 성장·물가 4국면 예측과 확률 기반 자산배분 연구계획

- 보고일: 2026-10-18 KST.
- 상태: **연구계획 보고본. 신규 실험은 아직 등록·실행하지 않았다.**
- 사용자 확정 사항: 골디락스·오버히트·리세션·스태그플레이션의 4국면, 국면 예측과 자산배분을 연구의 중심으로 한다.
- 추가 반영: **ML을 주요 비교로 포함한다. 규제 로지스틱과 LightGBM을 동등한 주 모형으로 두고, 둘의 예측·배분 성과를 직접 비교한다.**
- 기본 범위: 한국 경제의 월간 국면, 국내 주식·국채 ETF의 원화 총수익률, 월간 판단과 리밸런싱. 금·현금의 투자자산 추가는 본 계획에 포함하지 않는다.
- 이 문서의 수치 설정은 실행 전 등록할 기본안이다. 정확한 원천 ID·시작/종료월·가용 표본은 자료 게이트에서 확정한다. 성과를 본 뒤 유리한 정의로 바꾸지 않는다.
- 기존 연구 v3는 별도 탐색 연구로 보존한다. 기존 회귀·수익률 예측 결과를 새 4국면 연구의 결과로 재사용하지 않는다.

## 1. 연구 목표와 가설

**목표:** 판단 시점의 거시정보로 다음 달 4국면의 확률을 예측하고, 그 확률이 기존 국면의 지속·전이만 사용하는 방법보다 주식·국채 배분에 추가 가치를 주는지 검증한다.

| ID | 질문·가설 | 검증 결과물 |
|---|---|---|
| RQ1 | 네 국면은 한국 주식·국채의 수익·위험 분포를 구분하는가? | 국면별 관측·에피소드·전환 수, 자산별 수익·변동성·상관관계와 구간 |
| H1-L / 주 가설 | 로지스틱은 과거 국면 전이확률보다 다음 달 국면의 로그손실을 줄이는가? | 같은 판단월의 짝지은 OOS 로그손실 차이·동시 구간 |
| H1-M / 주 가설 | LightGBM은 과거 국면 전이확률보다 다음 달 국면의 로그손실을 줄이는가? | 같은 판단월의 짝지은 OOS 로그손실 차이·동시 구간 |
| H1-ML / 주 가설 | LightGBM은 같은 정보의 로지스틱보다 로그손실을 줄이는가? | **비선형 ML의 직접적인 예측 추가 가치** |
| RQ2 | 전환 시점과 각 국면의 확률을 적절히 예측하는가? | Brier score, 확률 보정, 국면별 recall·전환 지연·오경보 |
| H2-L / 주 가설 | 같은 국면별 배분정책에서 로지스틱 확률을 쓰면 전이확률보다 비용 차감 효용이 개선되는가? | 짝지은 순 CER 차이·동시 구간·위험/노출/회전율 |
| H2-M / 주 가설 | 같은 국면별 배분정책에서 LightGBM 확률을 쓰면 전이확률보다 비용 차감 효용이 개선되는가? | 짝지은 순 CER 차이·동시 구간·위험/노출/회전율 |
| H2-ML / 주 가설 | LightGBM 확률을 쓰는 배분은 로지스틱 확률을 쓰는 배분보다 순 CER이 높은가? | **비선형 ML의 직접적인 운용 추가 가치** |

- 국면 자체의 존재, 예측 가능성, 운용상 유용성을 서로 다른 주장으로 다룬다.
- 네 국면의 이름을 붙이는 것 자체를 학술적 새로움으로 주장하지 않는다. 기여 목표는 한국 자료의 정보시점·라벨 가용성·확률 평가와 공정한 배분 연결을 재현 가능하게 검증하는 것이다.
- 국면 정의와 미래 예측·배분이 연결되는 선행 프레임워크: [MSCI (2014)](https://www.msci.com/downloads/web/msci-com/research-and-insights/blog-post/what-fed-monetary-policy-has-meant-for-factors/what-fed-monetary-policy-has-meant-for-factors-Index_Performance_in_Changing_Economic_Environment.pdf), [Ang & Bekaert (2003/2004)](https://www.nber.org/papers/w10080). 해당 연구의 해외 성과를 한국에서 성립한 결과로 사용하지 않는다.

## 2. 4국면의 수치 정의

### 2.1 두 축의 기본안

- 성장 대표값 `g_m`: 한국 산업생산의 전년동월 성장률(%). 현재 확보한 OECD/FRED 산업생산 YoY를 우선 검토하되, 장기 원천·빈티지 계약이 충족돼야 채택한다. 산업생산을 한국 실질 GDP 전체의 성장률로 부르지 않는다.
- 인플레이션 대표값 `pi_m`: 한국 전체 소비자물가지수의 전년동월 상승률(%), `100 × (CPI_m / CPI_(m−12) − 1)`.
- 성장 모멘텀 `G_m = mean(g_m, g_(m−1), g_(m−2)) − mean(g_(m−3), g_(m−4), g_(m−5))`.
- 물가 모멘텀 `I_m = mean(pi_m, pi_(m−1), pi_(m−2)) − mean(pi_(m−3), pi_(m−4), pi_(m−5))`.
- 두 모멘텀은 %p 단위다. 기본 경계는 0이며, 정확히 0이면 상승/개선 쪽으로 분류하는 결정 규칙을 등록한다. 결측은 다른 국면으로 채우지 않는다.
- 정확히 필요한 관측월을 사용한다. 미래값 보간·전체 표본 분위수·양방향 필터·사후 GDP 경기판정으로 기본 라벨을 수정하지 않는다.

### 2.2 이름과 조합

| 이름 | 내부 ID | 성장 모멘텀 | 물가 모멘텀 |
|---|---|---:|---:|
| 골디락스 | goldilocks | `G >= 0` | `I < 0` |
| 오버히트 | overheat | `G >= 0` | `I >= 0` |
| 리세션 | recession | `G < 0` | `I < 0` |
| 스태그플레이션 | stagflation | `G < 0` | `I >= 0` |

- 물가상승률의 둔화와 물가 지수의 하락을 구분한다. 이 연구의 리세션은 성장·물가 모멘텀 동반 둔화라는 명칭이며 공식 경기침체 판정과 다르다.
- 3개월 평활을 기본으로 사용하고, 1개월·6개월은 사전 지정한 민감도 분석으로만 보고한다. 좋은 투자 성과를 보인 평활 창을 주 정의로 다시 선택하지 않는다.
- 라벨의 경제적 타당성은 GDP·경기동행지수·공식 경기 연대기와 사후 대조한다. 대조 결과로 기본 라벨을 수익률에 유리하게 재작성하지 않는다.
- 드문 국면도 사용자 지정 네 국면 중 하나로 유지한다. 관측·전환이 부족하면 해당 추론을 ‘자료 부족’으로 보고한다.

## 3. 자료 확보와 현재 확인 상태

| 자료 | 현재 로컬에 확인된 범위 | 신규 연구에서 할 일 |
|---|---|---|
| 산업생산 YoY | 2007-01–2026-08, 236개월 | 동일 정의의 장기 이력으로 확장하고 발표·개정 이력 조사 |
| CPI 기본 시리즈 | 2007-01–2023-11, 203개월 | 계속 갱신되는 공식 전체 CPI 장기 원천을 확보; 기존 중단 시리즈를 임의 연장하지 않음 |
| KODEX 200·국고채3년 | 공동 일별 2009-07-29–2026-10-16, 4,240 세션; 월간 TR 206개월 | 기존 종가·분배금·교차 검증을 재사용하고 신규 시점 정보를 추가 |
| 단기·장기 금리, 미국 금리, 환율 | v3 취득·정의 기록 보유 | 새 변환·정보시점·사용권 계약에 맞춰 재검증 |
| 원유 가격 | 새 주 피처 후보 | 공식 원천의 동일 정의 이력·공개 시점·권리를 확인한 뒤 채택 |

- 거시 자료는 **1995년 이후 확보 가능한 최장 동일 정의 공통 표본**을 목표로 한다. 이는 확보 완료 주장이나 확정 시작일이 아니다.
- 국면 예측의 거시 학습은 ETF 상장 전 자료도 사용할 수 있다. 국면별 투자수익·배분정책 학습과 투자 성과는 실제 ETF 이력이 있는 구간만 사용한다.
- 국내 원천 후보는 국가데이터처/KOSIS·한국은행 ECOS, 대외 원천은 연준/FRED·EIA 등 원 제공기관이다. 정확한 시리즈·표 ID와 실제 다운로드 가능 여부는 R0 산출물로 확정한다.
- OECD는 CLI 등 단기 통계의 월별 공개 스냅샷 경로를 제공한다. **한국의 필요한 산업생산·CPI, 필요한 연도의 빈티지가 모두 있는지는 아직 확인하지 않았다.** [OECD 데이터 안내](https://www.oecd.org/en/data/datasets/oecd-composite-leading-indicators-clis.html).
- 거시 표본을 길게 확보해도 ETF 배분 표본이 함께 늘어나는 것은 아니다. 국가·시리즈 정의를 임의로 이어 붙이지 않는다.
- 공식 발표계획과 실제 발표 기록을 구분한다. 예를 들어 2026년 9월 CPI는 10월 2일, 같은 달 산업활동은 10월 30일로 **보도계획**이 제시돼 있다. 같은 관측월이라도 국면 라벨의 가용일은 다를 수 있다. [공식 10월 보도계획](https://mods.go.kr/newsPln.es?mid=a10305000000&oa_mm=10).
- 원자료는 허용 범위 안에서 로컬에 보관하고 URL·취득 UTC·해시·단위·빈티지를 남긴다. 공개 저장소는 자체 통계·그림·재현 코드 중심으로 구성한다.

## 4. 정보시점과 학습 라벨

- 판단 시각은 기존과 같은 월말 마지막 공동 거래일 **18:00 KST**다.
- 예측 대상은 판단월 `t` 다음의 **관측월 `t+1` 국면**이다. 산출물에는 `decision_datetime`, `target_month`, `feature_observation_month`, `available_datetime`, `vintage_id`를 별도 열로 저장한다.
- 현재 관측 가능한 가장 최근 국면은 `t`보다 오래된 월일 수 있다. 당시 미공개였던 현재 월의 라벨을 ‘현재 국면’ 기준예측에 넣지 않는다.
- 학습 사례의 라벨은 성장·CPI와 필요한 후행월 값이 cutoff까지 확보돼야 사용한다. 배분정책 학습은 해당 라벨과 체결 간 자산수익이 **둘 다** 알려진 사례만 사용한다.
- 1차 목표 라벨은 두 지표가 처음 함께 가용해진 빈티지에서 계산한다. 각 과거 월을 서로 다른 기준년·빈티지의 값으로 임의 조립하지 않는다. 최신 수정치의 라벨은 보조 비교로 저장한다.
- 월별 아카이브에서 처음 찾은 스냅샷이 실제 최초 발표 빈티지와 같다고 가정하지 않는다. 최초 발표본인지, 후속 아카이브의 최초 확인본인지 구분하며 전자를 확인하지 못하면 그 라벨의 실시간 복원 상태를 검증 완료로 쓰지 않는다.
- 첫 공통 빈티지를 복원하지 못한 기간은 최신 수정치와 명시적 가용 가정을 이용한 **pseudo-OOS 연구**로 분리한다. 시차 버퍼를 실제 과거 발표시각으로 기록하지 않는다.
- 같은 달 두 지표의 발표시차 차이, 한·미 휴장과 서머타임, 공급자 반영 지연을 점검한다. 미확인 시점·빈티지는 null로 보존한다.
- 월간 국면 타깃과 ETF 체결~체결 수익률은 별개다. 보유구간에 대응하는 주된 달의 국면을 연결하되, 월말~월말 수익을 체결 손익으로 대체하지 않는다.

## 5. 예측모형과 입력 정보

### 5.1 주 입력 기본안

| 피처 | 목적 |
|---|---|
| 가장 최근 가용 성장 모멘텀 `G` | 성장 상태의 지속·변화 |
| 가장 최근 가용 물가 모멘텀 `I` | 물가 상태의 지속·변화 |
| 한국 10년−3개월 금리 스프레드 | 국내 금융여건·경기 기대 |
| 미국 10년 금리의 월간 bp 변화 | 대외 금리 여건 |
| 원/달러의 월간 변화율 | 대외·환율 여건 |
| 원유 가격의 월간 변화율 | 물가에 연결되는 원자재 정보 |

- 성장·물가 입력의 관측월 나이를 추가로 기록하고 모형에 포함한다. 따라서 기본안은 6개 거시 피처와 2개 가용성 나이 피처다.
- 모델 입력은 cutoff까지 가용한 값으로만 만든다. 시장자료도 관측일을 공개일로 대체하지 않는다. 기존 H10/H15 시점 문제를 재검사한다.
- 피처의 계수 유의성·SHAP·OOS 수익률로 주 입력을 사후 선정하지 않는다. 정의·접근이 미충족이면 실행 전 새 계약에 변경 이유를 기록한다.

### 5.2 모형과 튜닝 예산

| 구분 | 모형 | 역할 |
|---|---|---|
| FREQ | 과거 국면 빈도 + Dirichlet 1 평활 | 무조건부 기준 |
| PERSIST | 마지막 가용 국면에 97%, 나머지 각 1% | 단순 지속 기준 |
| MARKOV | 4상태 전이 빈도 + 행별 Dirichlet 1 평활 | **주 예측 비교 기준** |
| MACRO_LOGIT | L2 규제 다항 로지스틱 회귀 | **공동 주 모형: 해석 가능한 선형 기준** |
| MACRO_LGBM | native LightGBM 4.6.0 multiclass | **공동 주 모형: 비선형·상호작용 예측** |

- MARKOV는 가장 최근 가용 국면에서 목표 관측월까지 남은 개월 수만큼 전이시킨다. 최근 라벨이 `t−2`인데 한 번만 전이해 `t+1` 예측이라고 부르지 않는다.
- MACRO_LOGIT는 4개 공동확률을 직접 출력한다. 두 개의 이진확률을 독립성 가정 없이 곱하지 않는다.
- 로그손실은 평균 cross-entropy 기준, 피처 계수에 L2를 적용하고 절편은 벌점에서 제외한다. 규제 후보는 `[0.01, 0.1, 1, 10]`의 4개다. 스케일러·규제 선택은 학습 내부에서만 적합한다.
- 내부 검증은 가용 학습사례의 마지막 24개 월별 시계열 origin을 사용하는 기본안이다. 각 내부 cutoff에서도 아직 공개되지 않은 라벨을 제외한다. 모든 비교 모형이 같은 origin·완성 타깃을 사용한다.
- 확률 비교가 목적이므로 임의 oversampling·SMOTE·균등 클래스 가중치로 실현 빈도를 바꾸지 않는다. 로그 계산의 공통 수치 하한은 `1e-12`로 고정한다. PERSIST의 97/1/1/1은 기준모형의 확률 명세이며 학습 모형의 작은 확률을 1%로 올리는 규칙이 아니다. 과신에 따른 큰 예측 손실을 임의 clipping으로 숨기지 않는다.
- LGBM은 공식 native 4.6.0 버전을 고정하고 `objective=multiclass`, `num_class=4`를 사용한다. 얕은 트리·작은 leaf 수의 4후보, 최소 leaf 20, L2=5, 학습률 0.03을 기본으로 한다. 후보 상세·seed·iteration·thread 수를 실행 전에 등록한다. 모형 선택의 주 지표는 같은 로그손실이다. [공식 버전별 파라미터](https://lightgbm.readthedocs.io/en/v4.6.0/Parameters.html).
- 로지스틱과 LGBM은 같은 라벨·피처·정보시점·학습사례·OOS·내부 origin·기본 후보 수 4개를 공유한다. 후보 수를 맞추는 것이 알고리즘의 계산량이나 복잡성이 같다는 뜻은 아니다. 후보별 실행시간·선택 빈도도 기록한다.
- 월간 자료에서 광범위한 모델 탐색을 하지 않는다. 이번 주 비교의 학습 모형군은 로지스틱과 LightGBM으로 고정한다. 새로운 ML 모형을 추가하면 실행 전 비교군과 탐색 예산도 함께 새로 등록한다.

### 5.3 확률 보정을 주 비교에 포함

- 주 비교는 각 모형의 **학습 내부 보정 확률**로 수행한다. 미보정 확률도 같은 표에 보조 결과로 저장해 개선이 상태 정보에서 왔는지 과신 완화에서 왔는지 살핀다.
- 로지스틱·LGBM과 주 기준 MARKOV에 동일한 temperature 후보 `[0.5, 1, 2]`를 적용한다. `T=1`은 보정하지 않는 선택이다. 로지스틱/LGBM은 기본 후보 4개×temperature 3개, 총 12개 설정을 같은 내부 origin의 로그손실로 선택한다. MARKOV는 사전 고정한 전이 평활을 유지하고 temperature 3개만 비교한다.
- temperature는 해당 라벨로 학습하지 않은 **과거 방향의 내부 OOF raw score**에서만 선택한다. 최종 OOS나 모델의 자기 학습 적합값으로 보정하지 않는다. 내부 예측이 부족하면 양쪽 모두 사전 고정한 `T=1`로 환원하고 해당 월을 표시한다.
- 주 확률은 `softmax(raw_score / T)`다. 4개 클래스별 자유로운 보정함수를 추가하지 않는다. 작은 보정 표본의 불확실성도 보고한다. [확률 보정과 temperature scaling의 설명](https://scikit-learn.org/stable/modules/calibration.html).
- HMM은 본 계획의 필수 범위에 추가하지 않는다. 경제적으로 고정한 네 라벨을 잠재 상태의 사후 이름으로 바꾸는 문제를 먼저 피한다.

## 6. 표본과 OOS 설계

- 거시 예측 초기 학습: 완성·가용 라벨 **120개월 이상**, 각 국면 최소 12개월을 계산상 시작 기준으로 제안한다. 이는 검정력 보장이 아니다.
- 국면별 배분정책 초기 학습: 체결 간 수익과 국면 라벨이 모두 가용한 ETF 사례 **84개월 이상**. 부족한 국면의 정책은 아래 수축 규칙으로 전체 정책에 접근시킨다.
- 평가 시작 후보는 다음 달 관측월 **2017-09**다. 시작일·끝일은 데이터 범위와 위 시작 기준만으로 R0에서 최종 확정한다. 주 모형 성과를 본 뒤 기간을 줄이지 않는다.
- 모든 모형과 전략은 같은 평가월·완성 타깃을 사용한다. 국면 라벨이 아직 미공개인 최신 월은 예측 파일에는 남기고 국면 점수에서는 제외한다. 투자 손익만 먼저 확정된 월은 별도 잠정 표로 구분한다.
- 평가월 목표는 최소 96개다. 충족하지 못하면 주 연구를 충분한 장기 검증으로 표시하지 않고 기간·범위 제한을 먼저 보고한다.
- 매월 expanding 방식으로 재추정하고 내부 검증에서 선택한 후보만 해당 월 OOS에 사용한다. 추정·정규화·정책 선택에 미래 정보를 넣지 않는다.
- 기존에 사용한 2009–2026 구간은 이미 검토한 역사 자료다. 새 시계열 분할을 독립적인 미열람 확인 표본으로 부르지 않는다. 새 국면모형의 결과를 보기 전 계획을 등록하는 것과 진정한 독립 확인을 구분한다.
- 전향 검증은 향후 판단 시점에 입력 해시·네 확률·정책·비중을 저장하고 이후 라벨과 손익이 확정될 때 평가한다. 짧은 전향 기록만으로 충분한 검정력이 생겼다고 주장하지 않는다.

## 7. 국면 확률을 자산배분에 연결하는 방법

### 7.1 기본 투자 제약과 국면별 정책

- 자산: KODEX 200·KODEX 국고채3년. 주식 비중 30–70%, 나머지 국채, 공매도·레버리지 없음.
- 각 학습 cutoff에서 국면별 자산 기대수익을 계산한다. 국면 평균 `mu_s`는 `n_s/(n_s+24)`를 국면 평균에, 나머지를 전체 학습 평균에 주는 수축 추정치를 기본으로 한다. 24개월은 작은 국면의 극단적 평균을 완화하기 위한 사전 설정이며 성과로 조절하지 않는다.
- 공분산은 모든 국면에 공통으로 직전 가용 60개 체결 간 수익에서 추정한다. 무조건부 공분산에는 손익이 확정된 사례를 쓰고, 조건부 평균에는 손익과 국면 라벨이 모두 가용한 사례만 쓴다. 주식·국채 상관계수를 대각 방향으로 10% 수축하는 기본안과 양의 정부호 검사를 적용한다. 국면별 작은 표본으로 네 개 공분산을 따로 자유 추정하지 않는다.
- 각 국면의 정책 비중 `w_s`는 `mu_s' w − (gamma/2) w' Sigma w`를 위 비중 제약에서 최대화한다. 기본 `gamma=5`로 고정한다. 이는 월간 평균-분산 정책의 설정값이며 최적 투자자 선호라고 주장하지 않는다.
- 학습에 한 번도 나오지 않은 국면은 전체 평균 정책으로 환원된다. 상태를 없애거나 미래 수익률로 정책을 채우지 않는다. 해당 월의 관측 부족을 출력한다.
- 성장·물가 국면별 선호 자산을 교과서적 순위로 고정하지 않는다. 네 정책은 **가용한 과거 수익에서만** 추정한다.

### 7.2 확률 혼합과 비교 전략

주 정책은 `w_t = Σ_s P(S_(t+1)=s | I_t) × w_(s,t)`다. 불확실할 때도 네 확률을 보존한다.

| 전략 | 비중 결정 | 비교 목적 |
|---|---|---|
| SAA | 주식·국채 50/50 | 정적 기준 |
| POOLED | 국면을 구분하지 않은 전체 평균·같은 공분산·같은 목적함수 | 동적 정책 자체의 비교 |
| LAST_STATE | 마지막 가용 국면에 해당하는 `w_s` | 새 국면 예측이 없는 기준 |
| MARKOV_ALLOC | MARKOV 확률과 `w_s`의 혼합 | **주 운용 비교 기준** |
| MACRO_ALLOC | MACRO_LOGIT 보정 확률과 같은 `w_s`의 혼합 | **공동 주 운용 전략: 선형 예측** |
| LGBM_ALLOC | LGBM 보정 확률과 같은 `w_s`의 혼합 | **공동 주 운용 전략: ML 예측** |
| RETURN_TAA | 기존 과거 수익률 기반 Ridge 전략, 공통 평가월 재실행 | 실용적인 외부 전략 비교 |

- LAST_STATE·MARKOV_ALLOC·MACRO_ALLOC·LGBM_ALLOC은 **매월 동일한 네 정책 비중**을 공유한다. 달라지는 것은 국면 예측 확률이다.
- 주 증분 비교는 MACRO_ALLOC−MARKOV_ALLOC, LGBM_ALLOC−MARKOV_ALLOC, **LGBM_ALLOC−MACRO_ALLOC**이다. 두 공동 주 전략은 같은 학습 정책 비중·비용·제약을 공유하므로 마지막 비교에서 예측 모형의 운용 차이를 확인한다. RETURN_TAA는 타깃·정책이 다르므로 두 전략의 차이를 거시정보만의 인과적 효과라고 해석하지 않는다.
- 주식·국채가 함께 하락하는 상황에서 두 자산만으로 완전 방어할 수 있다고 주장하지 않는다. 금·현금의 확대 실험은 실제 투자수단 자료와 새로운 공통 평가구간을 확보한 뒤 별도 계획으로 다룬다.

### 7.3 체결·비용

- 기존 엔진의 첫 공동 양의 거래량 세션 종가 체결, 체결 전 갭의 기존 보유분 귀속, 비중 드리프트, 자기금융 NAV 회계를 유지한다.
- 기본 편도 10bp를 실제 매수+매도 거래금액에 적용한다. 0·5·25bp 민감도와 분배금 재투자 비용을 보고한다.
- ETF 실제 자료에 근거하되 배당락일 재투자·종가 체결을 가정하는 이론적 백테스트다. 지급일까지의 결제·미수금·시장 충격·용량 검증과 구분한다.

## 8. 평가·검정력·성공 판정

### 8.1 국면 예측

- 주 지표: 평균 multiclass 로그손실. H1-L은 `MARKOV 손실 − LOGIT 손실`, H1-M은 `MARKOV 손실 − LGBM 손실`, H1-ML은 **`LOGIT 손실 − LGBM 손실`**이다. 모두 양수일수록 해당 학습 모형 또는 ML의 개선이다.
- 보조: multiclass Brier score, macro-F1, balanced accuracy, 국면별 precision/recall, 확률 보정과 표본 수.
- 전환 진단: 과거 실제 국면의 전환을 사후 기준으로 삼아 첫 탐지 지연·오경보·전환별 성공/실패를 기록한다. 같은 전환 뒤 여러 달을 독립적인 성공 사건으로 세지 않는다.
- 국면별 자산 분포 분석은 RQ1의 기술 결과다. 많은 국면×자산의 차이 검정을 추가하면 사전에 보정군을 별도 등록한다.

### 8.2 자산배분

- 주 운용 지표: `CER_annual = 12 × (mean(r_net_monthly) − gamma/2 × var(r_net_monthly))`, `gamma=5`. 평균-분산 효용의 연율 근사이며 실제 무위험 확정수익을 뜻하지 않는다.
- H2-L은 `CER(MACRO_ALLOC) − CER(MARKOV_ALLOC)`, H2-M은 `CER(LGBM_ALLOC) − CER(MARKOV_ALLOC)`, H2-ML은 **`CER(LGBM_ALLOC) − CER(MACRO_ALLOC)`**이다.
- CAGR·연환산 변동성·현금 프록시 차감 Sharpe·일별 MDD·회전율·평균 목표/드리프트 노출·하락월 성과를 함께 보고한다. CER만으로 꼬리위험이 모두 반영됐다고 주장하지 않는다.
- 정책/비용 민감도는 gamma 2·10, 수축 12·48개월, 비용 0·5·25bp다. 기본 결과를 좋은 민감도 설정으로 교체하지 않는다.

### 8.3 불확실성과 검정력

- 예측 3개·운용 3개의 **총 6개 주 비교**를 하나의 가족으로 고정하고 가족 단위 95% 동시 구간을 보고한다. 6개 비교의 Bonferroni 분위수를 적용한 짝지은 원형 블록 부트스트랩 **20,000회**·기본 6개월 블록, 3·12개월 민감도를 사용한다. 비교 수 증가에 따른 꼬리 분위수의 재표집 횟수를 늘리되 이를 원자료의 관측 수 증가로 해석하지 않는다. 점별 구간과 동시 구간을 구분한다.
- 같은 월의 국면 손실과 각 전략의 수익을 함께 재표집한다. 월·모형·정책 대응을 깨지 않는다. 이 구간은 실현된 OOS 경로에 조건부인 기술적 구간이며 학습 전체의 불확실성을 완전히 복원하지 못한다.
- 사전 실무 최소효과 제안값은 로그손실 **0.02 nat/판단월** 개선, 순 CER **연 0.50%p** 개선이다. 이는 운영 복잡성 대비 판별할 효과의 설계값이며 이미 얻은 성과에서 역산하지 않는다.
- 개발 구간의 시계열 내부 검증 손실·수익 변동성만으로 **6개 비교의 보정 기준**에 따른 80% 검정력 근사 MDE를 각각 계산한다. ML을 주 비교로 올리면서 늘어난 다중비교 부담을 반영한다. 이전 두 비교 계획이나 v3 연구의 MDE를 그대로 사용하지 않는다. 국면별 지속기간과 전환 수에 대한 민감도를 함께 보고한다. 개발자료에 조건부인 설계 민감도임을 명시한다.
- 계산상 120개월·국면당 12개월·OOS 96개월을 충족하더라도 작은 효과를 충분히 탐지한다고 주장하지 않는다. 최소효과를 판별하기 어려우면 ‘검정력 제한’으로 연구 지위를 먼저 낮춘다.

| 예측 | 배분 | 결론 |
|---|---|---|
| 개선 | 개선 | 국면 예측과 운용 연결의 추가 가치 지지; 표본·빈티지 한계 병기 |
| 개선 | 개선 미확인 | 국면 예측은 개선됐지만 이 배분정책의 경제적 가치는 미확인 |
| 개선 미확인 | 개선 | 배분 점추정/구간과 발생 시기를 검토; 일반적인 국면 예측 우위는 주장하지 않음 |
| 개선 미확인 | 개선 미확인 | 이 정보·모형·정책 조합의 추가 가치를 확인하지 못함 |
| 어느 쪽이든 자료/검정력 부족 | 어느 쪽이든 | 효과 부재와 구분해 ‘판단 제한’으로 보고 |

- 주 비교의 동시 구간 하한이 0을 넘는지와 실무 최소효과를 달성했는지를 별도로 보고한다. 통계적으로 양수라는 것과 충분히 큰 운용 가치를 같은 의미로 쓰지 않는다.
- 위 판정표는 각 공동 주 모형의 MARKOV 대비 비교와 LGBM의 LOGIT 대비 비교에 각각 적용한다. MARKOV만 이기고 LOGIT을 이기지 못하면 ‘ML의 선형 대비 추가 가치 확인’으로 쓰지 않는다. 예측 우위와 운용 우위를 구분한다.

## 9. 주요 ML 비교·해석·실패 분석

- LightGBM의 전체 예측·배분 성과표를 본문의 로지스틱 결과와 같은 위치에 보고한다. 같은 4개 라벨·피처·가용시각·평가월로 multiclass 예측한다. 회귀 SHAP 코드를 그대로 재사용하지 않고 클래스별 출력 형태를 검증한다.
- OOS에서 각 클래스의 raw score에 대한 SHAP 합계+expected value를 검사하고, softmax 후 예측확률과의 연결을 확인한다. SHAP을 확률의 가산 기여나 인과효과로 오인하지 않는다.
- raw score의 SHAP 합산에서 temperature 적용·softmax·최종 네 확률·혼합 비중까지 계산을 연결한다. 온도 보정 후 점수의 기여는 raw 기여를 T로 나눈 것이지만, 확률과 비중의 기여까지 가산적으로 분해됐다고 주장하지 않는다.
- 국면별·시점별·입력 그룹별 기여, 국내/대외 정보 제거 민감도, 전환 실패 사례를 보고한다. 특히 ML이 자신 있게 틀린 월, 선형보다 나았던 전환, 드문 국면의 성과와 회전율 증가를 점검한다. SHAP을 보고 주 피처를 다시 고르면 새 실험으로 등록한다.
- 개선이 특정 기간·국면에 집중되는지, 라벨 평활을 바꾸면 순위가 유지되는지, 확률 보정 전후 예측·배분 결론이 달라지는지 확인한다. 보조 분석을 보고 주 모형·정의·평가기간을 바꾸지 않는다.
- 두 모형은 성과 확인 **이전부터 공동 주 모형**으로 등록한다. 외부 OOS를 보고 하나를 골라 그 모형만 대표 성과로 제시하지 않는다. 운용용 승자 선택이나 앙상블은 별도 사전등록이 필요한 후속 연구로 둔다.

## 10. 단계별 실행과 중단 기준

| 단계 | 작업 | 종료 시 제출물·수용조건 |
|---|---|---|
| R0 자료·권리·시점 | 성장·CPI 장기 자료, 대외 피처, 실제 발표·빈티지 범위 확인 | 정확한 원천 계약, 다운로드 증거, 결측·범위·실시간/pseudo 구분, 고정 평가월 |
| R1 라벨·사전등록 | 모멘텀·보합 규칙, 4국면 빈도·에피소드·전환 수·개발 검정력 진단 | 설정/입력 해시와 개발/평가 구간을 먼저 등록한 뒤 개발 자료만으로 MDE 계산; 최소효과·모형·비교·비용 고정, 자료부족 사유 |
| R2 국면 예측·주 ML 비교 | 기준·로지스틱·LightGBM walk-forward, 같은 내부 확률 보정 | 공동 주 확률 경로, 3개 주 손실 차이·구간·보정·전환 진단 |
| R3 국면 배분·주 ML 비교 | 같은 국면 정책을 세 모형 확률에 적용·비용 엔진 | 3개 주 CER 차이, 동일 정책 비교표, NAV·비용·노출·불확실성 |
| R4 해석·안정성 | 클래스별 OOS SHAP·정보군 제거·보정/평활 민감도·실패 사례 | 기여도 합산 검사, 시기·국면별 비교와 부정 결과 |
| R5 문서·공개 | 결과 대조·재현 검증·README 정리 | 실제 결과만 반영한 본문·부록·코드·표·그림·실험 원장 |

- 성장·CPI의 동일 정의 장기 이력, 원천 사용권 또는 필수 정보시점을 확인하지 못하면 관련 실행을 보류한다. 신뢰할 CPI 없이 4국면 결과를 만들지 않는다.
- 빈티지를 복원하지 못하면 실시간 검증을 보류하고 명시적인 pseudo-OOS 범위로만 진행한다. 국면 수를 줄여 사용자 요구를 우회하지 않는다.
- 희소 국면의 관측·전환 부족은 그대로 공개한다. 성과를 위해 국면을 합치거나 임계값·표본을 바꾸지 않는다.
- 새 설정 변경은 새 실험 ID, 실패·중단도 원장에 기록한다. 기존 v3 등록과 결과를 덮어쓰지 않는다.
- 연구 결과가 나오기 전에 새 README를 성과 포트폴리오처럼 게시하지 않는다. 별도 PDF 보고서는 만들지 않는다.

## 11. 구현·검증·최종 산출물

- 기존 TypeScript 수집·스냅샷·as-of·등록·체결·비용·블록 추론 구조를 재사용한다. 새 4국면 라벨·분류·정책 학습·multiclass ML 모듈을 추가한다.
