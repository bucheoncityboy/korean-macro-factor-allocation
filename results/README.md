# 연구 산출물

현재 연구는 **[four-regime/](four-regime/)** 아래에 있다. 성장·물가 네 국면의 예측, 로지스틱/LightGBM 비교, 동일 정책의 ETF 배분, 원천/정보시점 감사와 모든 사전 지정 민감도를 포함한다.

이 디렉터리의 기존 루트 파일과 다른 폴더는 이전 수익률 요인 연구(v1)의 기록이다. 새 4국면 연구의 성과로 합쳐 읽지 않는다. 공유한 ETF 원천 감사는 `data-quality.json`에 보존했다.
