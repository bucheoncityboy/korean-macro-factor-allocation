# 글로벌 ETF: 자산별 2국면과 경제 4국면

- **질문:** 국면 정의의 효과와 XGBoost의 추가 가치를 분리해 비교한다.
- **상태:** 자료 감사 후 실행 계약을 고정하는 단계. 실증 완료를 주장하지 않는다.
- **평가기간:** 2014-01–2025-09, 연속 141개월. 원래 목표는 2026-09까지 153개월이었다.
- **사전 변경:** 2025-10 CPI 관측치 부재가 3개월 대 3개월 라벨 6개월에 전파되어, 성과 계산 전에 사용자가 기간 단축을 확정했다.
- **주 비교:** XGB 2국면 − XGB 4국면; XGB 2국면 − 로지스틱 2국면; XGB 4국면 − 로지스틱 4국면.
- **성공 기준:** 실제 자료·공정한 비교·정보시점 검증·재현성. 양의 성과나 유의성을 요구하지 않는다.
- **자료:** SPY·EFA·EEM·IEF·TLT·LQD·IYR·GLD, 현금 BIL, INDPRO·CPIAUCSL ALFRED 빈티지.
- **공개 범위:** 역사적 순차 응용·대조 연구. 원논문의 수치 재현이나 미열람 전향 검증이 아니다.
- **방법:** [프로토콜](configs/protocol.json) · [방법과 해석](docs/methodology.md) · [자료와 출처](docs/data.md).
- **재현:** Python 3.12, `uv sync --frozen` 후 `uv run etf-study acquire → audit → run → verify → report` 순서로 실행한다.
- **기존 연구:** `legacy-korean-study-20261018` 태그에 보존했다. 저장소 URL은 유지한다.
