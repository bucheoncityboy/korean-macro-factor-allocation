# 공개 자료로 가능한 원문 방법 검증

사용자는 원문 Bloomberg 자료나 저자 전체 재현 패키지에 접근할 수 없으며 **공개 자료만 사용**하는 조건을 유지했다. 따라서 이 단계의 목표는 고정한 8개 ETF에서 원문에 명시된 방법과 실제 계산을 대조하는 것이다. 원문과 동일한 12개 지수·1991–2023년 자료를 확보했다는 뜻은 아니다.

## 검증 범위와 판정

- [공개 자료 범위](../configs/public_reconstruction_scope.json)와 [검증 계약](../configs/public_method_verification_contract.json)을 실제 검증 전에 커밋했다. 이전 ETF 성과를 열람한 사실을 명시했다.
- ETF 투자 대상·자료·학습창·선택 격자·배분·거래는 기존 계약대로 유지했다. 추가 포트폴리오 백테스트나 성과에 따른 설정 탐색은 하지 않았다.
- 아래 검증은 계산의 일치 여부를 확인한다. 원문 전체 실험과의 동등성, 동일 표본의 수치 재현, XGBoost 우위를 판정하는 검증이 아니다.

## 실제 자료 독립 계산 결과

| 검사 | 실제 결과 |
|---|---|
| ETF 수익8·시장5 특징 | 8개 ETF의 모든 일별 특징 대조 통과, 최대 절대 오차 약 9.72×10⁻¹⁵ |
| 금리 가용시점 | 기존 검색 방식과 별도의 merge_asof로 ‘해당 날짜보다 엄격히 이전인 관측값’ 재구성 |
| JM 라벨·국면별 평균 | 3개 경계 × 8개 ETF = 24건 독립 적합, 학습 라벨 해시·조건부 평균 대조 통과 |
| 다음 거래일 학습 표적 | 24건의 표적 정렬과 최종 학습 표적일 대조 통과 |
| EWM 공분산 | 대표 3개 경계의 행렬을 NumPy 가중 공분산과 대조, 최대 절대 오차 약 1.63×10⁻¹⁹ |
| 목적함수 단위 | 해를 손으로 구할 수 있는 경우에 공통 배율1/252 모두 같은 최적 비중, 단위검사 통과 |
| 기존 금융 산출물 | 기존 CSV·Parquet 41개 바이트 해시 동일 |

검사 경계는 2021-06-30·2023-12-29·2025-06-30으로 실행 전에 고정했다. 라벨 검사는 정확 일치, 특징·평균·공분산의 절대/상대 허용오차는 각각 10⁻¹⁰·10⁻¹²·10⁻¹⁴다. 같은 적합 함수를 호출하는 기존 재적합 검사와 별도로, 특징·금리 정렬·JM 평균·공분산을 별도 코드에서 계산했다. JM 학습 알고리즘 자체는 커밋을 고정한 저자 라이브러리를 사용했다.

## 저자 공개 자료 계산 대조

- [저자 저장소의 Nasdaq CSV](https://github.com/Yizhan-Oliver-Shu/jump-models/blob/d0fa00ce10126791695a259a45c5ddd41fbced80/examples/nasdaq/data/NDX.csv)를 사용했다. Git blob SHA·응답 SHA-256·URL·수집 시각을 보존하고 저자 저장소의 Apache 라이선스를 함께 보관했다.
- 이 CSV는 계산 검사 전용이다. Nasdaq을 연구의 투자 대상에 추가하지 않았다.
- 공개 예제의 5·20·60일, 9개 특징과 학습구간에서만 적합한 3표준편차 clipping·표준화를 별도 스칼라 계산과 대조했다. 최대 특징 오차는 약 7.11×10⁻¹⁵, 전처리 오차는 0이었다.
- 학습 2007-01-03–2021-12-31의 3,777일, 검사 2022-01-03–2024-09-27의 688일이다. 자료의 마지막 실제 날짜까지만 사용했다.
- 벌점0/50에서 저자 라이브러리가 출력한 온라인 상태와 전체 경로를 별도의 Bellman 계산·역추적으로 대조했다. 두 설정 모두 688일 상태가 정확히 일치했고, 미래 손실을 바꿔도 이전 온라인 경로가 유지됐다.
- 고정된 중심점에서의 상태 추론을 검사한 것이다. 비볼록 군집 적합의 전역 최적성을 증명한 것은 아니다.
- 저자의 노트북은 pickle 자료와 고정하지 않은 난수 상태를 사용한다. 이번에는 공개 CSV와 고정 시드를 사용했으므로 **저자 노트북 그림·숫자의 정확 재현으로 부르지 않는다**. 원문 표4/6/7의 재현도 아니다.

## 원문과 구현의 대응

| 항목 | 원문에서 확인한 방법 | 이번 구현·남은 차이 |
|---|---|---|
| 수익 특징 | DD log5/21, 평균·Sortino5/10/21 | 8개 식의 별도 계산 통과. adjust=False·워밍업·분모 하한은 적용 규약 |
| JM | 자산별2상태, 학습 내 표준화, 11년, 반년 갱신 | 같은 구조. DD 제외 대상의 IEF 매핑과 저자 실행 버전·초기화에는 한계 |
| XGB 입력 | 모든 자산 수익8+시장5 | 같은 구조. 주식–채권 상관은 SPY–IEF로 대체 |
| 분류 표적 | X[t]에서 다음 거래일 상태 예측 | 소스 대조와 학습 시점 검사. 실제 분류기 재적합·미래 교란은 기존 검증 기록과 함께 읽음 |
| XGB 설정 | 기본 하이퍼파라미터 | 2.1.4 실제 기본값 고정. 원문의 정확한 버전은 미확정 |
| 선택 | 직전5년 순차0/1 샤프, 반년마다 벌점 선택 | 같은 구조. 정확한 벌점 격자·평활 공동 선택 순서·초기화는 미확정 |
| 평균분산 예상수익 | 같은 JM 학습창의 예측 국면 평균 | 대표24건의 라벨·평균 대조 통과. 약세 제한은 아래 해석을 구분 |
| 약세 −10bp 제한 | §4.3의 cap 문구 | 수학적 상한 해석은 min(mean,−0.001)인 cap 계정이다. floor는 반대 방향의 해석이다. 저자 실행값이 없으므로 두 기존 결과를 공개하고 동등하다고 쓰지 않음 |
| 공분산 | EWM 반감기252 | 계산 대조 통과. 11년 절단·불편 정규화·지연 금리 기준은 적용 규약 |
| 배분 | 위험회피 기본MV5/국면10, 거래벌점0/1, 상한40% | 해당 구조와 공통 목적함수 배율 검사. OSQP는 Gurobi의 대체 |
| 현금 규칙 | 강세3개 이하이면 전액 현금 | 절대 문턱은 같지만 12개 중 최소4개와 8개 중 최소4개는 강도가 다름 |
| 자료·거래 | 지수·금리 대용 현금 | 실제 ETF·BIL 비용·종가 판단/다음 시가 체결은 명시적 차이 |

출처는 [원문 §3·§4](https://arxiv.org/html/2406.09578v2), [저자 예제](https://github.com/Yizhan-Oliver-Shu/jump-models/blob/d0fa00ce10126791695a259a45c5ddd41fbced80/examples/nasdaq/example.py), 고정한 구현·검증 계약이다. 예제의 adjust=True와 clipping을 원문 설정의 증거로 자동 채택하지 않는다. 발표 성과에 가까워지는 해석을 골라 결과를 바꾸지 않는다.

## 이 검증으로 좁혀진 것

검사한 특징·금리 정렬·대표 라벨/평균·공분산 계산에서는 불일치를 찾지 못했다. 따라서 해당 항목의 명백한 수식·정렬 오류가 원문과 다른 성과의 원인이라는 증거는 이번 검사에서 나오지 않았다. 검사하지 않은 전체 구현에 오류가 없다는 뜻은 아니다.

원문 자료 부재와 남아 있는 수치 규약 때문에 표본·구현·거래 차이의 효과를 완전히 분리하지 못했다. 기존 ETF 실험의 낙폭 감소, 샤프 개선 미유지, XGB/LR 우위 미확인이라는 관찰 결과는 그대로다. 이 계산 검증을 새로운 성과 개선이나 원문 실증의 재현 성공으로 해석하지 않는다.

## 재현

```bash
uv sync --frozen --python 3.12
# 기존 실제 ETF 원자료 스냅샷을 복원한 로컬 환경
uv run etf-study acquire
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 uv run python -m etf_regimes.public_method_checks verify
# 원자료 없이 공개 산출물·공개 CSV 계산 검사
uv run python -m etf_regimes.followup_snapshot restore
uv run python -m etf_regimes.redesign_snapshot restore
uv run python -m etf_regimes.public_method_checks artifacts
```
